# 昵称、签名、世界频道共用的词表。一行一个，# 开头是注释，空行忽略。
# （私聊、房间 / 局内聊天不用它 —— 见 docs/聊天系统设计.md 第四节。）
#
# 两种匹配方式（backend/app/text_guard.py 的 _compile_blocklist，大小写不敏感、NFC 规范化后）：
#   · 含中文等非拉丁字符的词：**子串**匹配 —— 「abc」会命中「xabcx」。中文没有词边界，
#     所以短词要谨慎：一个两字的词很容易误伤正常的话（例如「妈的」会拦掉「我妈的手机」，所以没收）。
#   · 纯拉丁字母的词（英文、马来文、方言拼音）：**整词**匹配 —— 「ass」不会拦 class / pass。
#     词尾写 * 表示前缀：「fuck*」拦 fuck / fucking / fucker。
#
# ⚠️ 这不是「敏感词系统」。真正能扛住的中文过滤要处理谐音、拆字、同形字、
# 插入符号，那是独立项目或者接第三方（阿里云 / 腾讯云内容安全）。
# 这份表只是三层管控里最外面的一层，见 docs/玩家资料系统设计.md 第六节。
# 2026-09-27 世界频道第一版只靠本地规则（用户定），所以第一次往里填了常见的脏话，以后按举报慢慢补。
#
# 改这个文件**不用重启后端** —— backend/app/text_guard.py 按 mtime 重新加载。
# 文件不存在也不会报错，等于空表。
#
# 部署：deploy/update.sh 会把这个文件复制到运行目录（和 avatars.json 一起）。
