# Glory Beta 0.04

Godot 4.6 rewrite of Glory v0.1. This folder is the clean Beta 0.04 project. Older beta folders and Google Drive content are reference only and are not overwritten.

Primary rule document: `docs/Beta 0.04.md`.

## Setup for collaborators

Two things are intentionally NOT in this repository:

1. **`assets/` (~4.9GB)** — art, audio, and 3D models are shared separately via cloud drive. Ask the project owner for the link, then place the folder at the project root as `assets/` before opening the project in Godot.
2. **`export_presets.cfg`** — contains the Android release keystore password, shared privately. Only needed for building release exports; the game runs in the editor without it.

Requires Godot 4.7.
