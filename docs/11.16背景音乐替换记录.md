## 播放规则

- **同一首不从头放**：正在放的已经是这个界面那组里的一首，就接着放（房间 → 主菜单 → 玩家资料一路不断）。
- **回到之前的歌接着放**：从商城 / 备战界面 / 图鉴回主菜单，接回原来那首、原来的位置；再进商城、备战界面、图鉴也接着上次的位置。抽宠物 / 祈愿弹窗关掉后，商城那首从打开弹窗前的位置继续。
- **主菜单什么时候重新随机**：进入对局时（`MusicService.begin_match()`，本局只生效一次）清掉记录，打完回主菜单 / 房间重新随机挑一首。
- **摆放界面 / PvE 战斗整局固定一首（11.18）**：开局第一次进摆放界面时从摆放界面 1~3 随机挑一首，第一次进 PvE / Boss 战斗时从战斗演示 1~2 随机挑一首，整局都用这两首（`MusicService.play_match_group()`）。摆放和战斗交替换曲时，回到同一首**从头放**。回到主菜单 / 排位组队房 / 自定义 3v3 房间（`MusicService.end_match()`）算这局结束，下一局重新随机。选曲只存内存，游戏闪退后重连回同一局会重新挑一次，之后这局固定用新挑的。
- **结算音乐只在详情页**：「胜利 / 失败」大字页不放；对局历史里回看详情不放。输赢口径与大字页一致（`Main._game_over_kind()`），平局放失败那首。
- 单首放完循环这一首，不会自动切到同组下一首。
