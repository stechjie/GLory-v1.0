# Beta 0.04 宝藏效果总表

更新时间：2026-06-05

本文档记录当前项目中的宝藏抽取规则、套装效果、单件宝藏效果与联动效果，方便快速读取与调参。  
数据来源：

- `data/treasure/treasures.json`
- `scripts/treasure/TreasureService.gd`
- `scripts/battle/BattleSimulator.gd`
- `scripts/battle/StatusEffectService.gd`
- `scenes/prep/PrepScreen.gd`
- `scenes/main/Main.gd`
- `scenes/battle/BattleScreen.gd`

## 全局规则

| 类型 | 当前规则 |
|---|---|
| 宝藏上限 | 最多拥有 5 个宝藏 |
| 宝藏回合 | 第 4 / 8 / 12 / 16 / 20 回合战后触发宝藏选择 |
| 宝藏候选 | 每次显示 3 个未拥有宝藏 |
| 选择倒计时 | 无时间限制 |
| 超时规则 | 不会超时自动选择，必须手动选择一个宝藏 |
| 宝藏刷新费用 | 50 / 100 / 200 / 400，之后继续翻倍且无上限（800 / 1600 / …） |
| 套装激活 | 同一类别拥有 4 个宝藏后激活该类别套装 |
| 金钱套影响 | 4 金钱激活后，商店刷新和宝藏刷新免费 |
| 战斗类作用对象 | 默认只作用于我方普通棋子，不作用于佣兵和法阵友军 |

## 状态说明

| 状态 | 当前实现 |
|---|---|
| 中毒 | 默认持续 4 秒，每 1 秒造成目标最大生命 3% 真实伤害 |
| 失血 | 默认持续 3 秒，每 1 秒造成目标当前生命 6% 真实伤害；目标 HP <= 1 时不会继续造成伤害 |
| 打断 | 目标下一次攻击时间延后 0.35 秒，并获得 0.35 秒打断状态 |
| 眩晕 | 持续期间无法行动 |
| 沉默 | 当前状态服务标记为会阻止技能 |
| 冰影响 | 冰属性会造成移动/攻速降低 1.5 秒，并添加冰影响标记 |
| 冰易伤 | 受到伤害 +15%，当前由瘫痪枷锁联动施加 |

## 套装效果

| 套装 | 激活条件 | 效果 |
|---|---|---|
| 4 防御 | 拥有 4 个防御宝藏 | 我方普通棋子开战时 HP +30%，DEF +30%，闪避 +15% |
| 4 控制 | 拥有 4 个控制宝藏 | 每次攻击使目标新增负面状态时，随机额外触发一种负面状态 |
| 4 攻击 | 拥有 4 个攻击宝藏 | 我方普通棋子优先攻击当前生命比例最低的敌人 |
| 4 金钱 | 拥有 4 个金钱宝藏 | 商店刷新和宝藏刷新免费 |
| 4 元素 | 拥有 4 个元素宝藏 | 我方普通棋子攻击时 20% 概率触发元素爆发，对目标周围 180 范围内敌人造成其最大生命 15% 真实伤害 |

## 实现差异与待确认

|---|---|
| `link_clearance_sale` | 已改为通过所需两件宝藏自动识别并生效 |

| 黄金祭坛次数 | 当前实现是每回合最多 3 次 |
