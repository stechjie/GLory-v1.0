# 10.10 赤律族棋子上商城

## 拍板

- 赤律族的 8 个棋子放进商城卖（游戏币）：T1 100、T2 200、T3 300，合计 1,600。
- **集齐 8 个才解锁种族**。买到一半只是收集进度，对局里用不了（理由见 `backend/app/shop.py` 顶部「棋子与种族」）。
- 老玩家不干涉：这次更新前已经有的账号直接补发整套；更新后注册的新玩家要去商城买。
- 游戏币不够由活动发放（运营自己送），价格不跟产出挂钩。

## 改了什么

| 位置 | 内容 |
|---|---|
| `data/shop.json` | 8 个 `kind=unit` 棋子，内容 id 是 `unit:<棋子 id>`；1 行 `kind=race` 的赤律族（`enabled=false`，`requires` 列出 8 个棋子） |
| `backend/app/shop.py` | `grant_content()`：发棋子时如果凑齐了，同一事务里发种族；先锁钱包行，防并发两笔各数到 7。目录加载时校验种族/棋子写法 |
| `backend/app/mail.py` | 邮件附件改走 `grant_content()`，邮件发最后一个棋子也会解锁种族 |
| `backend/app/routes/shop.py` | `unit` 加进 `DECLARED_KINDS`（旧包看不到棋子）；回执多一个 `unlocked` 字段 |
| `database/031_crimson_grandfather.sql` | 给第一次执行时已存在的账号补发种族和 8 个棋子；`one_time_grants` 记一笔，重跑不会多发 |
| `scripts/account/UnitCollection.gd` | 商城和备战页共用的规则：内容 id 前缀、哪一族在卖、集齐几个 |
| `scenes/menu/ShopScreen.gd` | 新「棋子」页：背景图 `assets/ui/shop/crimson_unit_bg.png`，中间种族 logo（外圈 8 段 + 从下往上点亮），左右各 4 个棋子；买到第 8 个弹「去备战」 |
| `scenes/menu/PetScreen.gd` | 种族页：没解锁的种族 logo 压暗，点 logo 或按钮弹「去商城」 |
| `scenes/main/Main.gd` | 商城 → 备战种族页、备战 → 商城棋子页的跳转 |

## 🔴 部署顺序

1. **先**在数据库执行 `database/031_crimson_grandfather.sql`（会打印补发了多少行）。
2. **再**部署后端（`data/shop.json` 与 backend 代码）。
3. 客户端出新包。

顺序反过来的话，中间那段时间老玩家的赤律族会被出战名片去掉（不报错，只是选了也用不了）。
