## 二、为什么走 `GloryTokens` + `variant`，而不是直接内联

两条项目硬约束决定了实现方式：

1. **`procedural_ui_ratchet_check` 盯计数**：扫 `scenes|ui|scripts`，统计 `Button.new()` / `StyleBoxFlat.new()`，
   迁移期**只许降不许升**。`MainMenu.gd` 的基线是 `4 Button + 1 StyleBox`（`data/qa/procedural_ui_baseline.json`）。
   → 所以本批**一个 `StyleBoxFlat.new()` 都不新增**，所有 StyleBox 一律走 `Tokens.flat_box(...)`；
   `_dialog_button()` 仍然复用那 1 个 `Button.new()`，只是多接一个 `variant` 参数分流配色。
2. **页面不写内联颜色**：把 `#0D1410` / `#C9A227` 等全部提升为 `GloryTokens` 的 `MIST_*` 常量，
   防止同一套金/墨绿散落在多处。`MIST_NONE`（全透明）是给「只要描边、不要底色」的 StyleBox 用的占位。

`_dialog_button()` 的**默认 `menu` 变体一字未改** —— 这个工厂同时供给主菜单自己的按钮（`_add_text_button`），
改成深色会把整张羊皮纸菜单一起带进去。房间面板的新配色全部走新变体：
`room_primary` / `room_second` / `room_ghost_gold` / `room_ghost` / `room_row` / `room_row_full`。

## 三、结构与尺寸

面板从「一条 HBox 硬摆」改成三段式 VBox：

```
CenterContainer (RoomPanel, 全屏铺底, MOUSE_FILTER_IGNORE)
└─ PanelContainer  ← _room_panel_box()  (800×540, 深墨绿@88%, 金 2px 描边, 圆角 16, 内边距 32, 柔和投影)
   └─ VBox (separation=22)
      ├─ _room_title_row()   「自定义房间」26 + 右侧「刷新」幽灵金按钮     (高 46)
      ├─ _room_divider()     1px 金@40% 细分隔线
      ├─ HBox body (separation=28)
      │  ├─ VBox left (300 宽, separation=18)
      │  │   ├─「创建房间」主按钮 (52 高, 实心金)
      │  │   ├─ LineEdit 输入房间 ID (46 高)
      │  │   ├─「加入房间」次按钮 (52 高, 透明底金描边)
      │  │   └─ _room_status 状态提示 (13 号, 灰绿)
      │  └─ VBox right (fill, separation=16)
      │      ├─「可加入房间」小标题 (18 号)
      │      ├─ ScrollContainer → VBox _room_list_box (行距 8)
      │      └─ _room_empty_box  空状态（与列表**互斥显隐**）
      └─ _room_footer_row()  「关闭」幽灵按钮 (52 高)
```

尺寸常量集中在 `MainMenu.gd` 顶部 `ROOM_*` 块（`ROOM_PANEL_SIZE` / `ROOM_PAD` / `ROOM_GAP_SECTION` /
`ROOM_GAP_COLUMN` / `ROOM_GAP_LEFT_COLUMN` / `ROOM_COLUMN_LEFT` / `ROOM_TITLE_ROW_H` / `ROOM_BUTTON_H` /
`ROOM_INPUT_H` / `ROOM_ROW_H` / `ROOM_ROW_GAP` / `ROOM_RADIUS` / `ROOM_RADIUS_PANEL` / `ROOM_FONT_*` / `ROOM_ICON_SIZE`），
照 `方案C §三` 的 1× 值落。

**空态与列表用两个兄弟节点互斥显隐**：`ScrollContainer` 在 Godot 里没法「填满且居中」，
所以空态单独做一个 `PanelContainer`（`size_flags_vertical = EXPAND_FILL`），`show_room_list()` 里按
是否有房间切 `_room_scroll.visible` / `_room_empty_box.visible`。两者都是右栏子节点，几何天然重合。

## 五、组件样式要点

- **主按钮**：实心金 `MIST_GOLD_BRIGHT`(#E5C558)，文字 `MIST_ON_GOLD`(#1A1206)，hover 金@10% 叠层，
  外发光只用在这一处（`shadow_color` = 金@35%）。
- **次按钮**：透明底 + 金 2px 描边，文字 `MIST_GOLD_BRIGHT`，hover 底 `MIST_HOVER_TINT`。
- **幽灵按钮**（刷新/关闭）：透明底 + 低对比描边（刷新金 1px、关闭 `MIST_GHOST_EDGE`），文字分别
  `MIST_GOLD_BRIGHT` / `MIST_TEXT_SOFT`。
- **输入框**：底 `MIST_INPUT_BG`(白@8%)，描边金@40%，focus 时描边转亮；placeholder `MIST_PLACEHOLDER`。
- **房间行三态**（`_room_row`）：常态 白@6% / 描边 `MIST_LINE` / 房名 `MIST_ROW_NAME` / 人数 `MIST_TEXT_MUTED`；
  悬停 白@11% / 描边金 / 人数转 `MIST_GOLD_BRIGHT`（靠 `mouse_entered`/`mouse_exited` 换字色）；
  满员 白@4% / 全字 `MIST_TEXT_MUTED` / `disabled = true`（同时禁点击，用 `disabled` 样式槽）。
- **空态**：44×44 放大镜图标（用两个 `Panel` 拼「圆环 + 45° 手柄」，**不新增图标资源**）+ 15 号
  `MIST_TEXT_MUTED` 文案，容器 白@5% / 圆角 12。

★ 透明底按钮必须同时覆写 `font_color` / `font_hover_color` / `font_pressed_color` / `font_focus_color`，
否则 hover 时文字会退回主题默认色（深底上几乎看不见）——`_style_room_button()` 里统一处理。

## 六、方案 C §五 三个 Godot 坑的落地

1. **`StyleBoxFlat` 无渐变** → 主按钮金色渐变**退化为纯色** `#E5C558`（方案推荐路径，零新增资源）。
2. **毛玻璃无内置** → 用「深墨绿 `#0D1410`@88% + 大范围柔和阴影」近似。设计稿写的是 2× 像素的
   y=20 / size=60，折半后 y=10 / size=30；工程里再收到 **size=24 / offset(0,10)**，
   避免大面积阴影在低端机采样过重（已在 `_room_panel_box()` 注释里注明理由）。
3. **项目零中文字体** → **不引入字体**，保持现有字体，靠 26 号字号 + 金色 + 描边拉层级。

**一处刻意偏离设计稿**：面板金描边用 **2px** 而非稿子的 1px。原因是面板在
`_layout_scale ≈ 0.77` 下渲染，1px 描边会被亚像素插值糊掉、近乎不可见，2px 才稳定可辨。
其余尺寸均按稿子 1× 值。
