# 10.08 语音与组队房修复记录

用户 10-08 反馈两件事：

1. 「自定义房间里，我在上排，上下两排说话我都听得到；一换到下排第一个座位就没声音了。」
2. 「把排位和休闲的房间对照自定义房间，看少了什么、补上；现在排位和休闲的房间全是 bug。」
   另外要求：**所有用到语音的地方，正在说话的人头像上要有个小麦克风**。

当天定的（用户逐条回复）：
- 自定义房间语音做 **B 方案**：开局前全房间互相都听得到，开局后才按「队友 / 所有人」分；
- 组队房上线语音配置、5 个 bug 全修、功能对齐自定义房间、**房主可以踢人**；
- **休闲和排位一样，只能单人或满 3 人**开始匹配。

---

## 一、换到下排就没声音：根因

协议 36 起六个人共用**一个** LiveKit 房间（`g<房号>-<随机串>-all`），但战斗服务器的
`_room_do_move` 还留着协议 31 时代「每队一个房间」的做法：**跨队换座就请 LiveKit 把这个人踢出语音房间**。
踢的是唯一那个房间，他只能断线重连；客户端 `VoiceService._sync` 同时也会因为「换了队」主动退房、重新要钥匙。
两边一起走，至少断几秒；踢人请求失败时会按 1 / 3 秒重试，晚到的重试还会把刚重连上的那一次再踢掉。

另外，换到对面之后，原来那一队的人如果是「队友」范围，本来就不再对你说话 —— 这是设计行为，
B 方案让开局前这一条也不存在了。

### 改法

| 哪边 | 改了什么 |
|---|---|
| 战斗服务器 `NetworkService._room_do_move` | 换座（含跨队）**不再踢人**。离开、被踢、被 AI 接管、关房照旧踢 |
| 客户端 `VoiceService._sync` | 换座**不重连**；钥匙与队伍无关，只按房间认（`_is_current_room`）。删掉 `_joined_team` / `_requested_team` |
| 客户端 `VoiceService._apply_audience` | B 方案：`lobby_open_to_room()` = 自定义房间（`match_mode == "custom"`）且服务器阶段是 `lobby` 时，麦克风对全房间开放；**匹配来的房间不开放**（陌生人） |
| `VoiceControls` / `VoicePanel` | 大厅阶段第三个按钮显示「全房间」，点了说明规则，不偷偷改开局后的设置 |

新客户端配旧战斗服务器也能用：只是跨队换座时还会被踢一次，按退避 2 秒后自己连回来。
所以两边可以分开上线，**不顶协议号**。

## 二、组队房（排位 / 休闲）

### 线上配置（不改代码）

账号服务器没有组队语音的 LiveKit 配置，`/v1/party/voice-token` 一直 503 —— 组队房的语音在线上**从来没通过**。
配法写进了 `deploy/README.md`「组队房语音」：把战斗服务器那份 `livekit_voice.json` 复制给账号服务器、加一个环境变量。

### 修的 bug

| # | 问题 | 改在哪 |
|---|---|---|
| 1 | 排位 / 休闲允许 2 人组队去排（设计文档写着只能单人或满 3 人，代码没拦） | `matchmaking.PARTY_SIZES`、`/v1/party/start` 回 409 并说原因；客户端按钮灰掉并提示 |
| 2 | 六人确认时有人拒绝 / 超时，剩下的人被**当单人**放回队列，而队伍房间在成桌时就关了 —— 三人队拆散、组队房跳回主界面 | `matchmaking._dissolve`：队里没人拒绝 → 整队放回组队队列最前面；队里有人拒绝 → 整队回队伍房间（`_party_back_to_room`），只罚拒绝的人。队伍房间改到**六人都确认**才关（`_finalise`） |
| 2b | 有人拒绝时拆桌产生的消息**算出来就丢了**（`leave()` / 断线回调都没发），另外五个人要等轮询才知道 | `Matchmaker._push` |
| 2c | 确认阶段按「离开队伍」或「取消」不算拒绝，那一桌会一直等他、超时还罚他 | `routes/party.py` 的 `leave` / `cancel` 都先 `matchmaking.leave()` |
| 3 | 组队语音每次开关麦都重新要钥匙，没连上时每 8 秒重试，撞账号服务器限流（每人每分钟 8 把）→ 429 | `PartyVoice`：同一房间 8 分钟内钥匙复用；失败按 2/4/8/15/30 秒退避，503 隔 30 秒 |
| 4 | 语音出错只写在悬停提示里（手机看不到）；503 后偷偷把档位改成关，图标还亮着、也不再重试；开着麦时关扬声器不生效；换房间（有人进出）会把玩家关掉的扬声器重新打开 | `PartyVoice` 重写；`PartyLobby` 在语音按钮右边显示原因 |
| 5 | 点了已过期的组队邀请，会每 30 秒拿同一个过期邀请重试，停在什么都点不了的房间 | `PartyLobby._load_room`：说明原因，然后照常进自己的队伍 |
| — | 全员确认后到进入对局之间，组队房的 7 秒轮询会查到「房间没了」把人拉回主界面 | `PartyLobby._match_ready` |
| — | 门禁 `party_lobby_rules` 原来就红：两条断言互相矛盾（一条禁止某行出现、另一条拿那行当锚点） | `party_notice` 改成 `match`；门禁按分支切片 |

### 对齐自定义房间补上的功能

| 功能 | 组队房怎么做 |
|---|---|
| 点队友头像 | 成员卡：查看资料 / 不听他的语音 / **移出队伍**（房主，排队中不能踢） |
| 房主踢人 | 新接口 `POST /v1/party/kick`；被踢的人先收到提示再退回主界面；踢完换语音房间（旧钥匙进不了新房间） |
| 快捷短语 | 聊天框标题栏「短语」，走同一个队内聊天接口 |
| 整局静音 | 右上角「静音」，与自定义房间同一个口径（Master 总线，不影响语音） |
| 开始键可按时脉动 | 同自定义房间 |
| 不听某人的语音 | 与对局里是**同一张屏蔽表**（`VoiceService.set_code_muted`），在组队房屏蔽了谁，进对局他还是被屏蔽 |

没补的：换座位、AI 座位、自测 —— 组队房只有真人、座位由匹配分配，不适用。

## 三、谁在说话：小麦克风

`VoiceControls.attach_speaking_mic` / `show_speaking_mic`，四处共用：

| 界面 | 挂在哪 |
|---|---|
| 组队房 | 三个座位的头像框右下角（`PartyVoice.speaking_codes` + 自己） |
| 自定义房间（含匹配房的大厅） | 六个座位头像右下角（`VoiceService.slot_speaking`） |
| 摆放界面 | 左上角那排六个头像 |
| 战斗界面 | **没有头像**，在三个语音按钮下面列「名字 + 小麦克风」，只列正在说的人 |

被我屏蔽的人说话不亮（我听不到他）。标记按头像比例缩放（锚点，不是像素），大厅头像随窗口缩放时跟着缩。
