# 10.08 语音与组队房修复记录

用户 10-08 反馈两件事：

1. 「自定义房间里，我在上排，上下两排说话我都听得到；一换到下排第一个座位就没声音了。」
2. 「把排位和休闲的房间对照自定义房间，看少了什么、补上；现在排位和休闲的房间全是 bug。」
   另外要求：**所有用到语音的地方，正在说话的人头像上要有个小麦克风**。

当天定的（用户逐条回复）：
- 自定义房间语音做 **B 方案**：开局前全房间互相都听得到，开局后才按「队友 / 所有人」分；
- 组队房上线语音配置、5 个 bug 全修、功能对齐自定义房间、**房主可以踢人**；
- **休闲和排位一样，只能单人或满 3 人**开始匹配。

## 一、换到下排就没声音：根因

协议 36 起六个人共用**一个** LiveKit 房间（`g<房号>-<随机串>-all`），但战斗服务器的
`_room_do_move` 还留着协议 31 时代「每队一个房间」的做法：**跨队换座就请 LiveKit 把这个人踢出语音房间**。
踢的是唯一那个房间，他只能断线重连；客户端 `VoiceService._sync` 同时也会因为「换了队」主动退房、重新要钥匙。
两边一起走，至少断几秒；踢人请求失败时会按 1 / 3 秒重试，晚到的重试还会把刚重连上的那一次再踢掉。

另外，换到对面之后，原来那一队的人如果是「队友」范围，本来就不再对你说话 —— 这是设计行为，
B 方案让开局前这一条也不存在了。

### 改法

| 哪边 | 改了什么 |
|---|---|
| 战斗服务器 `NetworkService._room_do_move` | 换座（含跨队）**不再踢人**。离开、被踢、被 AI 接管、关房照旧踢 |
| 客户端 `VoiceService._sync` | 换座**不重连**；钥匙与队伍无关，只按房间认（`_is_current_room`）。删掉 `_joined_team` / `_requested_team` |
| 客户端 `VoiceService._apply_audience` | B 方案：`lobby_open_to_room()` = 自定义房间（`match_mode == "custom"`）且服务器阶段是 `lobby` 时，麦克风对全房间开放；**匹配来的房间不开放**（陌生人） |
| `VoiceControls` / `VoicePanel` | 大厅阶段第三个按钮显示「全房间」，点了说明规则，不偷偷改开局后的设置 |

新客户端配旧战斗服务器也能用：只是跨队换座时还会被踢一次，按退避 2 秒后自己连回来。
所以两边可以分开上线，**不顶协议号**。

## 二、组队房（排位 / 休闲）

### 线上配置（不改代码）

账号服务器没有组队语音的 LiveKit 配置，`/v1/party/voice-token` 一直 503 —— 组队房的语音在线上**从来没通过**。

### 对齐自定义房间补上的功能

| 功能 | 组队房怎么做 |
|---|---|
| 点队友头像 | 成员卡：查看资料 / 不听他的语音 / **移出队伍**（房主，排队中不能踢） |
| 房主踢人 | 新接口 `POST /v1/party/kick`；被踢的人先收到提示再退回主界面；踢完换语音房间（旧钥匙进不了新房间） |

## 三、谁在说话：小麦克风

`VoiceControls.attach_speaking_mic` / `show_speaking_mic`，四处共用：

| 界面 | 挂在哪 |
|---|---|
| 组队房 | 三个座位的头像框右下角（`PartyVoice.speaking_codes` + 自己） |

| 摆放界面 | 左上角那排六个头像 |
| 战斗界面 | **没有头像**，在三个语音按钮下面列「名字 + 小麦克风」，只列正在说的人 |

## 1. 组队语音「尚未配置」

组队房语音和自定义房间是同一套（同一个 LiveKit、同一个手机端组件），区别只在**钥匙由谁签**：
自定义房间找战斗服务器，组队房（还没进任何对局）只能找账号服务器，而账号服务器上没有那份钥匙文件。
第一批写成了要人手动复制，线上没做。

改成 `deploy/update.sh` 自动做（`sync_party_voice`）：找到战斗服务器那份 `livekit_voice.json`，复制给账号服务器，
写好环境变量。找不到就打印原因、继续更新。

顺带：`update.sh` 自己被更新时，正在跑的那一份是旧版（文件头写过这个坑），新加的步骤那一次不会执行。
现在拉完代码发现脚本自己变了，就用新版接着跑（`--after-pull`）。**这一次是例外**：服务器上现在跑的旧版
还没有这个逻辑，所以这一次要跑两遍 `update.sh`，之后就不用了。

## 3. 换位（带进对局）

| 操作 | 现在 |
|---|---|
| 点空位 | 换到那个位置（`PUT /v1/party/seat`），排队中不能换 |
| 点队友的位置 | 看资料 |
| 房主点队友位置上的 × | 移出队伍（同自定义房间，点了直接踢） |
| 邀请 | 只在好友列表：点好友那一行 |
| 单独不听某人 / 谁在说话 | 长按扬声器出「队伍语音」面板（同自定义房间） |

第一批加的「成员卡」去掉了（功能分到上面这几处）。

**带进对局的链路**：`party.Room.seats`（成员 → 0~2）→ `/start` 把位置交给 `matchmaking.join_group` →
成桌时 `allocate_seats` 给六个人各定一个本队位置（满 3 人的队一定按他们选的；一队是几个单人时撞位先到先得）→
`Assignment.seat` → `/v1/battle/card` 的名片多一个 `seat` 字段 → 战斗服务器 `_matched_slot_for` 按它入座，
那个位置被占了才退回坐本队第一个空位。名片加字段向后兼容：旧战斗服务器不认识 `seat`，照旧按到达顺序坐。**不顶协议号**。
