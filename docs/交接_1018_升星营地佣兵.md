## 2. 代码现状（已读过的结论）

### 2.1 升星
- 1→2★、2→3★：`scenes/prep/PrepBoardController.gd` 的 `_combine_copies_auto()`（自动合成）和 `_merge_copies_into_cell()`（手动合成）只做 `keeper.star = star + 1` 后刷新，**没有任何特效和音效**。两处都已经记录了 `_last_merge_keeper_uid` / `_last_merge_uids`。
- 4★：只能用升级石，`_execute_four_star_upgrade()` → `play_four_star_upgrade.call_deferred(uid)`（`PrepBoardModels.gd`，调 `FourStarAuraV2.play_upgrade()`）+ `SfxService.star4_cue_for(id)`。
- 自动合成会连锁（9 个一星 → 三星），`_auto_combine_all()` 循环最多 60 次。
- 星级显示：格子下方 2D 标签「名字 ★星级」（`PrepWidgets.make_cell_caption`），3D 模型不带星级浮标。

### 2.2 萝卜营地入口亮光
- `PrepUI.gd` 建入口按钮时挂了 `StarBurst`（`_carrot_button_burst`）：冰蓝白 `Color(0.62,0.86,1.0)`、`radius_scale 1.3`、`base_alpha 1.0`、`short_ray_alpha 0.4`、`ray_width_scale 1.5`，10 根星芒**压在橙色徽章上面**。Leno 觉得难看（像贴纸/镜头光斑，冷暖冲突）。
- 显示条件在 `_refresh_carrot_counter()`：有任意升级石就亮（本地版还加了免费抽条件）。
- 营地面板里天/地/人三个石头格各自也有一层 StarBurst（`CarrotCampPanelV3._add_stone_counter`，`_stone_bursts`）。

### 2.3 营地面板与 4 星入口
- `CarrotCampPanelV3.gd`：两个页签「营地」「升级石」，**默认开在营地页**（`toggle()` 保留上次页签）。
- 4 星列表 `_refresh_four_star_list()` 在第二页；每行左边是**石头图标**而不是棋子头像；规则说明「对应升级石 ×1 → 三星棋子升至四星」在第二页最底部。
- 天/地/人库存是浮在面板左外侧的竖栏 `attach_stone_rail()`，只在第二页显示。
- 棋盘上可升 4★ 的三星棋子已有金色「可升」光环：`PrepBoardModels._sync_four_star_actor()` 里 `state == 1` → `FOUR_STAR_READY_AURA`（`fit_to_skeleton(..., 0.24)`）；已是 4★ 的用 `FourStarAuraV2`。
- `request_four_star_upgrade(where, index)` 已有「关营地 → `_overlay.show_unit(cell, _commit_four_star_uid)` → 确认」这条路。

### 2.4 团队佣兵检阅台乱站/超框
- `PrepUI._rebuild_team_mercs_stage()` 用 `_team_mercs_spot()` **随机撒点**：区域 `TEAM_MERCS_AREA_HALF = (0.42, 0.24)`、最小间距 `TEAM_MERCS_MIN_DIST = 0.15`、试 24 次；**试不出来就返回最后一个点（可重叠）**。
- 最多 3 个队友 × `GameState.MERCENARY_SLOTS = 8` = 24 个模型，区域放不下 → 挤成一团；撒到边缘的加上模型宽度 → 超出背景框。
- 朝向还随机 ±20°（`rng.randf_range(-20, 20)`）。
- 舞台：`TEAM_MERCS_STAGE_SCALE 3.2`，相机 `(0,2.4,1.9)` 看 `(0,0.05,0)`，FOV 40；脚下有队友颜色圈 `_make_team_mercs_plate`（`GameConstants.team_slot_color(slot)`）。
- 队友顺序：`GameConstants.team_first_slot(team_of_slot(my_slot))` 起连续 `TEAM_SIDE_SIZE = 3` 个 slot。

## 3. 已定方案（可以直接做）

### 3.1 团队佣兵：按队友分三排的固定站位 ✅
- 一个队友一排，共三排。**排序按颜色：最左边那个颜色（队伍第一个 slot，`team_first_slot`）在第一排（最靠前/离相机最近）**，依次往后。（如对「最左的颜色」理解有疑问，先问 Leno 是哪个界面上的颜色顺序。）
- 每排左侧一个 2D 小标签：队友名字 + 数量（如 `3/8`），颜色用 `team_slot_color`。
- 每排自动排开：间距 = `min(理想间距, 可用宽度 / 人数)`；人多时整排等比缩小模型，保证 8 个也不出框。
- 全部统一朝向镜头，去掉随机角度。
- 位置由「slot + 序号」决定，后买的追加在排尾，不挪动已有的。
- 替换掉 `_team_mercs_spot()` 随机撒点；`modal_lifecycle_check` 要继续通过。

### 3.2 萝卜营地入口提示：两级提示 ✅
Leno 的口径：**只要队伍里有升级石就要提示**（提醒队友有石头了）；能升 4★ 时要更强。
- **一级（队伍有石头）**：去掉现在的冰蓝星爆。改成按钮**背后**一圈柔和同色系呼吸光（参考 `SoftEdgeGlow`，放在徽章后面不压图）+ 右上角小角标（石头图标 + 数量）。
- **二级（有棋子能升 4★，判据复用 `GameState.four_star_check(cell).ok`，与 `_sync_four_star_actor` state==1 同口径）**：光变金、更亮；角标变成「4★」样式；**从不满足变满足的那一刻弹一下 + 一声提示音**，之后安静呼吸。
- 保留本地的免费抽条件（并入一级提示）。
- 营地面板里三个石头格的星爆去掉，改成「有存货时数字/图标变亮」。
- 同步更新 `tools/star_burst_check.gd` 守新口径。

### 3.3 升星特效：三档统一手感 ✅（地面环待重新设计，见 4.1）
- 实现方式：两个合成函数合成时把 `{uid, 新星级, 被吃掉棋子的位置}` 塞进待播列表，`_refresh_all()` 重建模型后 `call_deferred` 播放（照 `play_four_star_upgrade` 的写法）。连锁合成同一 uid 只播最终星级。
- 表现（已同意的部分）：
  - 被吃掉的棋子化成光点飞向保留的那枚（约 0.25s）。
  - 保留的棋子先压扁再回弹（Tween `TRANS_BACK`）；3★ 幅度更大。
  - 格子下方「名字 ★」的星星放大回弹；3★ 加金色闪光。
  - 音效：2★ 一声，3★ 音调更高。
  - **4★ 也补上同样的「弹一下」**，三档手感一致（Leno 已确认要）。
- 备战阶段**不做顿帧**（`Engine.time_scale` 会拖慢倒计时）。

Leno 希望面板上方的「营地」「升级石」两个页签做得更显眼，让玩家知道有两个入口。已提过的思路：

- 规则一句话放页面顶部：「三星棋子 + 同属性升级石 = 四星」。
- 长按棋盘上带金光的三星棋子，详情里直接出「用X石升至四星」按钮（需确认现在详情框里有没有）。
