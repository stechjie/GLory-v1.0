# 10.09 排位房：房主出战宠物「必须显示 + 锁死变暗 + 只听它脚步声」

> 本文对应 README 顶部 `2026-10-09（排位房）` 那一节。改动落在 `GLory-codex`，已同步 `GLory-v1.0`，**未做 git 操作**（提交由用户本地完成）。

## 0. 两轮需求（用户原话）

1. 第一轮：`把大厅和排位宠物显示功能不变，但是脚步声改成只听出战宠物的声音`
2. 第二轮：`在排位里，房主出战状态的宠物是必须显示的，那里的勾选设置为无法取消勾选，且为暗色。然后声音只听房主宠物的脚步声。而大厅，所有人只听自己出战的宠物的声音，显示所有宠物`
3. 真机复测反馈：`测试发现并没有实现勾选按钮变暗，且能取消掉备战宠物（老虎）`

## 1. 最终行为

| 场景 | 显示 | 发声 |
|---|---|---|
| 大厅 | 自己**全部**宠物（沿用原版） | **只听自己出战宠物**的脚步 |
| 排位房 | 房间共享的展示列表（房主用「展示宠物」抽屉挑，全队同一份），**但房主的出战宠物被强制加进去** | **只听房主出战宠物**的脚步（全队一致） |

## 3. 真机复测事故与修复（19:50）

**症状**：排位房里房主的备战宠物（老虎）那行显示成 `○`（未勾选）、**可点、没变暗**。

**根因（不是代码写错）**：客户端默认连**远程已部署后端**（`scripts/account/AccountConfig.gd` 的 `DEFAULT_BACKEND_URL = "https://glorytd-api.duckdns.org"`），本机**没有任何后端在监听**、也没有导出包 ⇒ 真机跑的是**编辑器 ＋ 远程服务**。而本批后端改动**只在本地 `backend/`** ⇒ 线上还是旧版 ⇒ 快照里**没有 `host_pet`** ⇒ `locked = false` ⇒ 不锁、不暗、还能点掉。

> ★ 教训：**「客户端连远程部署后端」时，改本地 `backend/` 不进真机**。凡依赖服务端新字段的功能，必须先把后端**部署/重启**，才谈得上生效。
> ★ 顺带证伪一个直觉：`_style_paper_button` **早就定义了 `disabled` 暗色样式**（`Color(0.66,0.67,0.63,0.74)` ＋ 字色 `d1c8ad`）⇒ **变暗实现没问题，是 `disabled` 从没被置真**。

**修法（只改客户端）**：`_host_pet()` 改走 `host_pet_of(...)`，加**客户端兜底**；`_display_pet_ids()` 接到 `configure_party_display`。
**局限**：客户端兜底**只覆盖房主本人**；非房主队友要看到/听到房主的宠物，**仍需线上后端部署**。
