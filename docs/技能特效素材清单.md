# Beta 0.04 技能特效素材清单

用途：整理当前游戏需要准备的技能 / 状态 / 元素特效素材，方便找素材和后续同步修改。

## 总览

| 分类 | 建议素材数 |
|---|---:|
| 通用战斗特效 | 12 |
| 元素特效 | 4 |
| 状态 / Debuff 图标或头顶特效 | 13 |
| 棋子主动 / 被动特效 | 28 |
| 佣兵特效 | 12 |
| Boss 特效 | 9 |
| 法阵友军特效 | 5 |
| PVE 小怪特效 | 17 |

建议优先找“通用可复用特效”，不要每个技能都找完全独立素材。第一版约需要 45-55 种素材即可覆盖大部分表现。

## 音频素材

| 类型 | 文件 | 用途 | 接入位置 |
|---|---|---|---|
| 战斗 BGM | `res://assets/audio/bgm/fighting_music.mp3` | 即时战斗期间循环/播放，战斗结束或战斗界面退出时停止 | `scenes/battle/BattleScreen.gd` |
| UI 音效 | `res://assets/audio/ui/start_game.mp3` | 点击新游戏并进入准备界面时播放一次 | `scenes/main/Main.gd` |
