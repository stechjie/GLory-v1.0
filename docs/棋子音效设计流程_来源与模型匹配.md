# 棋子音效设计流程：制作来源与模型匹配

适用项目：GLory；整理日期：2026-10-25。本文以本次已通过审核的音效设计为例，供以后新增棋子或重做音效使用。重点是声音的制作来源、观察模型的方法和音色选择依据；播放规则用于保证声音与画面同步。

> 推荐顺序：看模型与动作 → 看实际弹体、技能特效 → 确认材质和发声阶段 → 选择可复用音色或制作新音色 → 单独与混战试听 → 用户审核 → 接入本地。

## 一、音效从哪里来

### 1. 首先判断能否复用已通过审核的音色

新棋子不一定需要一套全新的声音。先比较武器材质、接触方式、体型力度和弹体形态：这些相近的单位可以共享音色，再通过细微变体减少重复。

- 已通过审核的基础音色：`assets/audio/sfx/approved_20261025/`。
- 已通过审核的音色变体和逐单位对应表：`ui/services/ApprovedBattleAudio.gd` 的 `VARIANTS`、`BASIC_CUES`。
- 其他现有技能、拉弓和合成素材的登记：`ui/services/SfxService.gd`。

复用前仍要在新棋子的动画中试听，不能只因单位同种族、同职业或音效名字相近就套用。例如：人类拿木杆应先考虑木质命中；怪物挥爪应考虑爪击；发射光矛不等于发射圆形法球。

### 2. 本次使用的制作来源：SoundsFree

用户提供的制作入口：[SoundsFree 音效生成网站](https://www.soundsfree.art/zh/)。本次通过其 **AI 代码入口**渲染声音，保存生成代码和 WAV，便于复现和调整。

本次素材采用原创程序合成：用滤波噪声制作风切、摩擦和打击的粗糙部分，用振荡器、短共振和音量包络制作主体、重量与魔法质感；没有引用第三方采样。这里的“合成”是制作声音的方法，与游戏里的“四星合成音效”不是同一概念。

后续使用该入口时：

1. 先写清声音设计说明，再生成候选或合成代码。
2. 在网站试听并实际渲染，不能只交一段描述或未经试听的代码。
3. 下载 WAV，同时保存可复现的代码、参数、版本和来源记录。
4. 生成结果不合适时，按“起音、主体、尾音”逐项调整，避免反复只写“更好听”。

用户当时将该网站作为免费可商用来源提供。后续制作、下载和交付时仍应记录当时适用的授权说明、日期及是否存在额外素材来源，不能把本文当作网站永久授权承诺。若改用其他来源，先确认素材来源和项目使用条件；不要从商业游戏、影视、短视频直接截取声音。

### 3. 保留制作来源，保证以后能改

每组音色至少保存以下内容：

|记录项|应填写的内容|
|---|---|
|音色 ID|稳定的英文名称，不只用“新音效1”|
|来源|制作网站／工具、制作日期；若用了外部采样则记录出处|
|制作材料|纯程序合成、录音或采样；哪些素材参与了混合|
|设计说明|对应什么材质、动作、体型和发声阶段|
|复现材料|生成描述、合成代码、参数、随机种子（适用时）|
|授权记录|适用说明的链接或留存文件；外部素材单独记录|
|输出及审核|文件名、版本、A/B/C 变体、用户通过或重做的意见|

## 二、怎样观察棋子，确定它应该发什么声音

### 1. 找到实际使用的模型，而不只看角色名字

先记录唯一的 `unit_id`，再对应模型、动画和配置。名字是检索入口，不能代替声音判断。

项目内可交叉查看：

|材料|主要用途|
|---|---|
|`assets/models/` 下棋子的实际场景、模型和贴图|判断武器、身体材质、体型和装备；确认运行时使用的是哪一版模型|
|模型的攻击动画，以及游戏里的攻击表现|判断挥砍、戳刺、拳击、爪击、拉弓、投掷或施法；看接触位置和发力幅度|
|`data/units/race_units.json`|玩家棋子 ID、普攻和技能配置|
|`data/mercenary/mercenaries.json`|佣兵配置|
|`data/boss/bosses.json`、`data/pve/pve_monsters.json`|Boss、PvE 怪物配置|
|`effects/vfx3d/units/OgaChessVFXCatalog.gd`、`OgaSkillVFXCatalog.gd`、`CrimsonVFXCatalog.gd` 及其引用|追踪实际弹体形状、属性特效和技能表现|
|现有审核音色与单位映射|比较能否复用，但不把旧映射当成永远正确的答案|

优先看游戏当前实际加载的模型与表现。仓库中的旧模型、备用弹体和兜底特效可能没有被运行时使用，不能看到一个文件就据此分类。

### 2. 至少看完整的一次攻击

建议留下三个阶段的截图或短录像：**攻击抬手 → 武器接触／弹体发出 → 命中与效果出现**。静态立绘通常只能确认外形，不能确认发声时机。

逐项回答：

- **声音由什么产生？** 剑刃、木杆、拳脚、爪子、岩石身体、弓弦、飞行物、能量球，还是命中的异常状态？
- **怎样运动？** 快速划过、重砸、刺入、连续摩擦、振弦、旋转飞行、聚能、爆开？
- **体量与力度如何？** 轻小灵巧还是厚重迟缓；不能把所有近战都做成同一声重锤。
- **材质是什么？** 金属、木、骨、甲壳、岩体、肉体或灵体。外观颜色只能辅助判断，蓝色不自动等于冰，绿色不自动等于毒。
- **实际听到的应该是哪一阶段？** 普攻金属命中要有接触感；箭矢飞行要有短风切；拉弓音对应弓弦张力；中毒音对应命中生效。
- **在正常战场视角下是否仍然匹配？** 模型展示镜头很近，实际棋盘里很小，声音不能因为展示细节丰富就变成夸张的长演出。

### 3. 看不清时先标记，不把猜测写成结论

若材质或动作不明确，写“暂按某类设计，待动画确认”，附截图、当前模型路径和判断理由。先做少量有差别的候选供审核，不一次制作大量缺乏依据的素材。

例如光之卫士：当前通过的方案使用轻刃音，但其晶体圣刃材质曾有争议。以后若模型改成明确的骨晶或晶体结构，应重新观察并试听；不要因为旧表写了金属就永久照搬。

模型动作、模拟器攻击方式和特效如果互相不一致，要分别记录，并说明当前设计采用哪项证据。本阶段不通过擅自改变攻击距离、技能或战斗数值来迁就声音。

## 三、按攻击方式选择音色

以下六类是基础，新增单位先逐个对照。分类针对“这次攻击的发声物”，不针对种族。

|类别|模型／动作证据|声音主体|容易配错的地方|
|---|---|---|---|
|1 金属武器近战命中|剑、斧、金属矛头或锤接触敌人|短刃切入、硬质瞬态和少量金属共振；重武器适当加厚主体|整声都做成敲铁铃，缺少命中身体的接触感|
|2 人类或近人类徒手命中|确实用拳、掌、脚或相似肉体部位攻击|紧凑的拳脚肉体冲击，少量摩擦|只因长得像人就把爪击归为拳击|
|3 怪兽／猛兽爪击命中|有爪、喙或明显抓挠撕裂动作|短促抓划、擦裂与接触；大兽增加重量|用拳声替代利爪，或额外加一整段吼叫|
|4 非金属武器近战命中|木杆、鼓槌等非金属武器接触敌人|木质或相应材质的短共振和钝击|只因是武器就套金属声|
|5 箭矢／实体投掷物飞行|箭、标枪、弩矢或实体投掷武器飞出|与尺寸、速度相符的短风切，必要时少量旋转感|把命中爆响放在弹体刚发出时|
|6 法球投射物飞行|形态是圆团状奥术、圣光或暗影能量球|紧凑的能量流动或脉冲，属性只作适量点缀|同色法球和光矛全部用同一声|

六类之外按需要扩展，不为每个种族强行新建一类：

- **有形魔法弹体**：光矛、血矛、光盘、羽刃等，兼顾能量属性与明确形状；矛突出穿行，盘突出旋转，羽刃突出轻薄。
- **甲壳／岩体／骨晶接触**：与拳脚、木杆分开考虑，体现硬质外壳、颗粒或石质重量。
- **灵体触击**：短促、轻薄的能量接触，避免做成真实拳头或长鬼叫。
- **特殊召唤落击**：如人王天堂剑，按已确认的召唤与落击表现单独设计，不硬套普通箭矢。

新建分类要记录“为什么现有类别不适合”，并检查是否真的需要新音色。多个细分类也可以共享一个通过审核的音色。

### 已有棋子的判断示例

|棋子|观察与匹配依据|本次通过的选择|
|---|---|---|
|民兵 `human_militia`|非金属武器攻击，不能因人类持械就归金属|木质命中 `melee_nonmetal`|
|魔童 `dark_imp`|爪击接触，不能当人类徒手|爪击 `melee_claw`|
|弓箭手 `human_archer`|普通箭矢飞行与技能拉弓是两个不同声源|普通 `proj_arrow`；技能触发攻击使用既有拉弓声|
|极光射手 `god_aurora`|普通弹体是光矛；四星攻击持续触发技能|普通分类 `proj_light_lance`；四星触发攻击只在弹体命中时播技能音|
|飞灵 `undead_fly`|不能从“飞”字判断成箭矢飞行；需看真实攻击和中毒生效|当前基础映射 `melee_claw`；四星中毒按真实命中阶段播放|

用户曾称“飞龙”的中毒棋子，本次按当前配置中的飞灵 `undead_fly` 对应。以后遇到名称歧义，先核对 ID，不能把它误套到黑龙技能。

## 四、把模型观察转成可制作的声音说明

### 1. 先写清三个声音层次

|层次|要解决的问题|例子|
|---|---|---|
|起音|玩家能否听懂动作刚发生了什么|短刃切入的清脆瞬态、弓弦张开的张力|
|主体|是否有正确材质、重量和属性|木头的短共振、兽爪的擦裂、法球的柔和能量|
|尾音|是否收得干净，能否承受密集触发|短衰减、极少量空间感；不给普攻铺长混响|

本项目的基调是 **Q 版奇幻、清楚、紧凑、有材质区别**。常规普攻避免长铃音、大空间混响、科幻枪声和无依据的吼叫。技能可以更有辨识度，但不能每个技能都做成持续数秒的轰鸣。

短小的高频细节不应刺耳；低频不应因很多单位叠加就变成闷响。区分轻重主要依靠起音、主体厚度和衰减，不只靠提高音量。

### 2. 可直接填写的生成描述模板

```text
用途：GLory 的 [普通近战命中／普通弹体飞行／技能拉弓／技能命中／四星合成]。
棋子：名称 [ ]，unit_id [ ]。
画面：Q 版奇幻；实际模型使用 [武器／身体部位]，材质为 [ ]。
动作：从 [ ] 到 [ ]；发力特点 [轻快／厚重／抓划／旋转／其他]。
发声阶段：[抬手／弹体发出及飞行／接触命中／状态生效／合成完成]。
听感：起音 [ ]，主体 [ ]，尾音 [ ]；与模型体型的关系 [ ]。
目标时长：[根据攻击速度和试听填写]；应在重复攻击时保留间隔感。
需要避免：[长尾／尖锐铃音／枪声／吼叫／过多低频／其他]。
输出：WAV，A/B/C 三个细微变体；保存设计说明和可复现代码／参数。
比较基准：现有通过的 [音色 ID／样音]；本次希望改变 [ ]。
```

三个变体应表达同一种材质和动作，只在音高、噪声纹理、力度或衰减上小幅变化。不能把 A 做成剑击、B 做成拳击、C 做成爆炸，再随机混用。

### 3. 两个填写示例

**小型木杆近战命中**：短、略干的木质敲击，起音明确，主体有轻微木腔感，辅以少量肉体接触；干净收尾。不带金属长响、不加吼声、不做沉重石锤感。对应的是接触敌人的瞬间，不把挥杆风声当成唯一主体。

**轻薄光矛飞行**：迅速前行的细窄风切，加少量圣光能量质感，轮廓利落、尾音短。不做圆法球的鼓动，不放命中爆炸，不加长铃音。如果这次攻击实际触发了四星命中技能，则按审核规则只保留命中技能声，不能再叠普通光矛飞行音。

### 4. 输出与响度的参考

本次通过的原创合成素材为 **44.1 kHz、16-bit、单声道 WAV**。后续可沿用，若有特殊需要再记录调整原因。素材首尾需平滑收束，无明显直流偏移、削波或不必要的前置静音。

本次设计峰值约为普攻 −6.4 dBFS、技能 −4.2 dBFS、合成 −3.3 dBFS，可作初始对照，不能当成统一响度标准：相同峰值的尖锐声音仍可能显得更响。不要把全部素材都归一到最大音量，最终要在现有 BGM 和真实混战下判断。

## 五、声音必须对应正确的画面时刻

音色匹配以后，再确认以下规则，避免“声音对了、时机错了”：

|情况|设计与播放约定|
|---|---|
|普通近战|命中敌人时播放接触音|
|普通远程|弹体生成／飞行阶段播放飞行音，不自动增加命中音|
|四星弓箭手拉弓技能|触发攻击抬手时播放；周期从当前配置与真实事件确认，不能只看技能名猜次数|
|佣兵星轨猎人拉弓|箭雨技能施法抬手时播放；同次出手不叠普通飞行音|
|四星极光射手|每次触发攻击的弹体命中时播放技能音|
|四星毒灵、飞灵中毒；四星刺灵破甲|跟随真实命中及效果生效；存在弹体时等待其到达|
|四星民兵眩晕等概率／条件技能|本次确实触发才用技能音；没触发仍用正常普攻音|
|格挡、反弹等防守技能|归于防守者，在来袭攻击命中时响，不误删防守者另一轮自己的普攻|
|备战四星合成|只表示合成／升星，绝不能作为未制作技能的兜底|

**对当前允许播放专属技能音的归属，同一次触发攻击只选择普通音或技能音。** 已制作且真实触发技能时，用技能音替代该次普通音；未制作技能继续不加新技能声，不拿合成音补位。声音被节流或优先级丢弃时，不另补一条普通音。敌方等归属的可听范围沿用现有规则，不能在设计新棋子时无意扩大。

一次攻击的随机触发、追加伤害或穿透目标，必须以真实事件为依据。多弹体、连击、多段技能要先明确“一次出手”和“每次命中”是否各有声音，不能直接对每条伤害事件都播放一次。

## 六、如何审核“配得上”

1. **模型与声音一起看**：用正常游戏视角观看攻击，回答材质、力度、体型和发声时刻是否相符。
2. **听单次与连续攻击**：确认一击清楚，连续多次不机械、不刺耳，A/B/C 仍像同一种动作。
3. **听与 BGM 的关系**：不要只在静音背景下把每条样音调得很响。
4. **做真实 3v3 混战试听**：加入不同材质近战、普通远程和触发技能，判断重要技能是否可辨，普通攻击是否过密。
5. **由用户审核**：逐项记录“通过／重做／待确认”，修改后更新版本；先审核声音和分类，再接入游戏。

审核包建议包括：模型／动作截图或录像、单位与音色对应表、WAV、复现代码／参数、来源记录，以及能播放单条和连续声音的审核页。重做时尽量保留原音对照。

混战编排试听可用于初筛密度，必须标明是编排；它不能代替游戏实际事件、优先级和混音产生的结果。实际游戏录音应记录阵容、星级、触发规则与测试范围，不把离线测试写成真实多人联机验收。

## 七、通过后的接入与交付要点

- 素材放入明确的新批次目录，例如 `assets/audio/sfx/<批次>/`，保留稳定文件名与 A/B/C 关系。
- 新棋子登记逐单位普攻映射；技能按实际事件类型接入。当前主要入口是 `ApprovedBattleAudio.gd`、`BattleAttackAudioPlanner.gd`、`SfxService.gd` 和 `BattleVfx.gd`，不要只改一个文件名就认为完成。
- 沿用现有层次：P0 场次 → P1 人王阵亡 → P2 技能 → P3 已确认暴击／击杀近战 → P4 法阵 → P5 低星法师技能 → P6 普通近战 → P7 普通远程。现有共享池 8 路，战斗层 PvP 6 路／PvE 7 路。具体归属、节流、抢占和响度按当前代码，不靠把所有新声音调响来争抢注意力。
- 检查技能／普攻互斥、低星与四星、触发与未触发、命中延迟、取消和战斗退出；随机音色变化不得消耗战斗随机数。
