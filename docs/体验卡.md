# 体验卡与背包改版（2026-11-20）

## 用户定下的规则

- **背包**：去掉头像和宠物（宠物在备战页换、头像在资料页换），分页改成 全部 / 道具 / 体验卡 / 礼物 / 活动。现在只有体验卡；道具、礼物、活动暂时是空页。
- **体验卡**对应三种东西：种族、宠物、棋盘皮肤。卡面沿用各自的图案：种族 logo、宠物形象、皮肤自己的卷轴（`shop_button.png`）。1/3/7 天卡是同一张图，卡框按天数区分：铜 / 银 / 金。
- **来源**
  - 宠物祈愿、樱花祈愿**没抽中**时三选一：只给游戏币 60% / 只给一张卡 30% / 两样都给 10%。卡的天数 1 天 60%、3 天 30%、7 天 10%。宠物卡从玩家还没拥有的奖池宠物里随机挑；皮肤卡就是祈愿的那张皮肤。
  - 商城「棋子」页，「还差 X 游戏币」下面一颗「体验该种族」按钮：1/3/7 天 = 100/200/300 游戏币。**每个账号、每个种族、每周各一次**，北京时间周一 0 点重置。
- 卡放进背包，**点「使用」才开始计时**；同一目标再用一张，时间往后叠。种族卡用了之后，出战种族不满 4 个会自动带上。
- 已永久拥有的目标：卡不能用，只能卖。**所有卡都能卖**，1/3/7 天 = 100/200/300 游戏币（买来的也能卖）。
- 背包里没用的卡**永不过期**。
- **到期提醒**：体验到期后，玩家第一次开始任何游戏（休闲 / 排位 / 建房 / 进房）前弹一次。
  - 有种族到期：「去修改」跳到备战页种族页签；「随机出战」从能用的种族里随机补满出战名单，然后继续开局。
  - 只有宠物 / 皮肤到期：它们自动换回默认，只弹一个「知道了」。

## 🔴 体验不是拥有

永久拥有只看 `player_entitlements`：集齐解锁种族、抽奖的「已拥有」、邮件领取、商城「已解锁」都只认它。体验放在 `player_trials` 里。「能不能用」= 两边合起来（`trial.read_usable`），只在出战那几处使用：存种族、换皮肤、设出战宠物、出战名片。

如果把体验写进归属表，用一张种族卡就能永久拿到这个种族。
