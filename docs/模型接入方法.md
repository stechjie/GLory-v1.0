# 模型接入方法

## 战斗演示模型规则

所有带 `model` 字段的棋子，都会在战斗演示界面使用同一套显示方法：

- 即时战斗使用一个共享 `Battle3DLayer`，里面只有一个透明 `SubViewport`、一个 3D 世界和一个主相机。当前战场模型为 `res://assets/models/arena/battle_scene.glb`，运行时会套用森林色调材质；回退背景为 `res://assets/board/battle_forest_arena_2_5d.png`。
- 所有存活角色模型统一挂到同一个 3D 根节点下渲染，避免每个棋子各开一个 `SubViewport`。`GLB` 使用 Godot threaded load 异步请求，避免进入战斗第一帧同步加载大模型导致黑屏/卡住。
- 2D 单位节点只保留血条、名字、脚下阴影和轻量站位轮廓；血条/2D阴影会从 3D 世界坐标投影回屏幕，跟随实际显示的模型位置；有模型的棋子不再显示蓝色方块，模型加载成功后会隐藏轮廓。
- 自动计算模型包围盒，让完整模型从头到脚显示在战斗场景中。
- 使用每个角色自己的 `BattleModel_*` 旋转节点，不直接旋转模型本体。
- 按固定间隔寻找最近的存活敌人，根据敌人方向旋转角色模型。
- PVE、Boss、PVP 都共用同一套朝向逻辑。
- 即时战斗模型使用显示层避让：战斗模拟坐标不变，但 3D 显示会按附近单位自动轻微错开，避免多个模型完全重叠。
- 观感参数集中在 `BattleScreen.gd` 顶部：`BATTLE_CAMERA_SIZE` 控制镜头远近，`BATTLE_ARENA_TARGET_WIDTH` / `BATTLE_ARENA_TARGET_DEPTH` / `BATTLE_ARENA_GROUND_Y` / `BATTLE_ARENA_YAW` 控制 3D 战场大小、落地高度和旋转，`BATTLE_PLAYABLE_WIDTH` / `BATTLE_PLAYABLE_DEPTH` / `BATTLE_PLAYABLE_OFFSET` 控制棋子实际可站战斗区，`BATTLE_UNIT_GROUND_Y` 控制棋子脚底贴合场地表面的高度；当前 battle_scene.glb 使用 `1` 贴合场地表面，`BATTLE_MODEL_WORLD_SCALE` 控制角色整体视觉大小，`MODEL_SEPARATION_*` 控制模型避让，`BATTLE_VISUAL_MIN` / `BATTLE_VISUAL_MAX` 控制战斗显示边界；`MODEL_FACING_PLAYER_YAW_OFFSET` / `MODEL_FACING_ENEMY_YAW_OFFSET` / `MODEL_FACING_LERP` 控制战斗模型阵营朝向稳定度；森林色调由 `BATTLE_ARENA_FOREST_TINT` / `BATTLE_ARENA_FOREST_ALBEDO` / `BATTLE_ARENA_FOREST_BLEND` 控制；背景压暗在 `_build()` 的 `arena_tint.color`。

## 单位数据字段

在 `data/units/race_units.json` 的单位里加入：

```json
"model": "res://assets/models/units/example.glb",
"model_visual_scale": 1.0,
"model_base_yaw": 180.0,
"model_frame_fill": 0.96
```

字段说明：

| 字段 | 用途 |
|---|---|
| `model` | 模型资源路径 |
| `model_visual_scale` | 模型导入尺寸修正，通常保持 `1.0` |
| `model_base_yaw` | 模型默认正面角度；如果角色背对敌人，优先调这个 |
| `model_frame_fill` | 全身在单位框中的占满程度；越大越满，过大可能贴边 |
| `model_idle_animation` | 可选：待机动画来源场景，适合分离 FBX 动作库 |
| `model_idle_animation_name` | 可选：待机动画名，魔童为 `mixamo_com` |
| `model_attack_animation_name` | 可选：主模型里的攻击动画名，魔童包装场景为 `attack` |
| `model_attack_sync_seek` | 可选：攻击造成伤害时从攻击动画的指定秒数开始播，用于让出拳和伤害同步；魔童当前为 `0.25` |
| `model_attack_lock_time` | 可选：攻击触发后保护 attack 不被 run/idle 打断的时间；光之卫士当前为 `0.45` |
| `model_run_animation_name` | 可选：移动时播放的动画名；光之卫士当前为 `run` |

## 调试顺序

- 战斗表现层会强制使用 `race_units.json` 里的最新模型/动画字段覆盖运行中单位 `def` 的旧字段，避免旧缓存导致新包装场景、`attack` 或 `run` 不生效。攻击表现同时监听 `attack_count` 和 `next_attack` 冷却窗口来触发，移动时按 3D 位移切 `run`。
- 包装场景如果提供 play_idle() / play_attack() / play_run()，BattleRenderer.gd 会优先直接调用这些方法；没有这些方法时才回退到直接播放 AnimationPlayer 动画。


1. 先确认完整身体显示。
2. 如果模型太小或太大，调 `model_frame_fill`。
3. 如果模型方向相反，调 `model_base_yaw`，常用值是 `0 / 90 / 180 / 270`。
4. 只有模型原始比例明显异常时，才调 `model_visual_scale`。
