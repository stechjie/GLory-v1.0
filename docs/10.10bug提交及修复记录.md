## 二、两条返工的根因（值得单独记）

### 追加 A：老虎移动消失

`pet_tiger_animated.tscn` 少了一行 `run_model_scale = 488.0`。查仓历史：这行是 `d755935`（10-07）加的，
被同事 `8c4cf64`（"import"，10-09 21:08）**删掉**；我 10-10 回灌时忠实带入了删除。
`ImportedPetAnimated` 切换跑步模型时按默认 1.0 缩放 ⇒ 老虎缩成一个点（看着就是"消失"），
而影子是挂在 pet 根节点下的**独立** `MeshInstance3D`，不受影响 ⇒ "影子还在"。
修法：按 `8c4cf64^` 逐字节恢复（560 字节、LF）。

### 追加 B：死灵气息在实战里一次都不出现

第一版只在 `BattleRenderer` 里判 `f.get("phoenix_used")`，但**真实对局播的是回放**，
而回放帧是 **13 列冻结结构**（`ReplayDigest.SIMULATION_TOP_FIELDS` 含 `frames`，加列会改掉玩法身份哈希），
roster 里也没有这个键 ⇒ 判据恒假。摆拍工具直接手填 `phoenix_used` 能过，**实战过不了** ——
这就是"截图好看、真机没有"的典型。

修法：**走 roster，不走 frames**，照 `twin_group_id` 的既有先例 ——

```gdscript
# BattleSimulator._replay_capture_roster
if f.has("phoenix_used"):
    roster[uid]["phoenix_used"] = bool(f.get("phoenix_used", false))

# BattleScreen._load_replay_roster（严格对称）
if r.has("phoenix_used"):
    f["phoenix_used"] = bool(r.get("phoenix_used", false))
```

只在**有键时**带 ⇒ 没触发凤凰的对局 roster 字节完全不变；`simulation_sha256` 只投影
`SIMULATION_ROSTER_FIELDS` 白名单里的字段，也不受影响。

## 三、死灵气息长什么样（第 10 条的设计约束）

三层，全部**加色混合**（`BLEND_MODE_ADD`，加法只能提亮、永远压不暗 ⇒ 结构上不可能遮死模型）：

1. **地面死灵纹章** `NecroticSigil`：水平 `PlaneMesh`，半径收在队伍圈以内、且高于队伍圈
   （不与四星光环抢同一条地面线）。
2. **上浮魂屑** `RisingSoulWisps`：`GPUParticles3D` + **环状发射器**（点发射就是从体内往外喷），
   环带外径收在队伍圈以内，粒子数受 `VFXQualityBudget` 封顶。
3. **剪影边光**：复用本仓既有的 `four_star_rim.gdshader`（Fresnel），alpha 由
   `dot(NORMAL, VIEW)` 的补角 `edge` 驱动 ⇒ 正对镜头处 alpha≈0，这是"不遮挡正面"的技术保证。
   ★ opacity 上界锁 **0.30**：实测 0.62 会把低面数模型的小腿整段染成荧光绿。
   四星光环在场时**让位**（不抢 `material_overlay`），消失后可逆恢复。

两张贴图（sigil / wisp）在**运行时生成并静态缓存**，不新增美术资源文件（也就没有 `.import` / 清单漂移）。
