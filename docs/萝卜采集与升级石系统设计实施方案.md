## 1. 功能目标

在现有备战界面增加一套第二资源经济：玩家通过宠物采集萝卜，用萝卜召唤当回合佣兵或抽取四星升级石。金币可以投资采集速度；持续用萝卜召唤佣兵，会自动提高萝卜储存上限，并增加之后每回合获得的固定金币收入。

这套系统形成一个清楚的循环：

```text
金币 → 提升萝卜采集速度 → 获得更多萝卜
萝卜 → 召唤佣兵 → 本回合战力 + 解锁更高容量和每回合金币收入
萝卜 → 抽升级石 → 团队共享 → 把对应属性的三星棋子升为四星
```

玩家每回合的核心选择是：用萝卜购买即时战力，还是保留萝卜抽升级石，为中后期制造四星核心。

## 2. 第一版规则

### 2.1 萝卜归属和结算时机

- 萝卜、采集科技、佣兵消费进度属于玩家个人，本局内永久保存，下一局重置。
- 每次进入新回合备战阶段时结算一次萝卜，包括第一回合。
- 实际到账为 `min(当前萝卜 + 本回合产量, 当前容量上限)`，超过上限的部分丢弃。
- 战斗中和停留在备战界面时不会按真实时间增加萝卜。
- 宠物挖掘动画是结算表现，不改变按回合计算的规则。

第一回合建议从 0 萝卜开始，进入备战后播放一次采集动画并获得 3 萝卜。这样玩家第一次看到动画时，资源数字会同步变化。

### 2.2 金币提升采集速度

基础采集速度为每回合 3 萝卜。金币升级提供额外产量，额外值采用“当前等级替换前一等级”的方式，不累计相加。

| 采集科技 | 本次升级价格 | 额外产量 | 每回合总产量 |
|---|---:|---:|---:|
| 0级 | — | +0 | 3 |
| 1级 | 100金 | +3 | 6 |
| 2级 | 200金 | +6 | 9 |
| 3级 | 400金 | +10 | 13 |
| 4级 | 800金 | +15 | 18 |
| 5级 | 1600金 | +25 | 28 |

表中的价格是逐级购买价格。例如从2级升3级支付400金，不能跳级。购买后立即显示新速度，从下次回合采集时生效。

### 2.3 召唤佣兵自动发展萝卜经济

不再设置单独的“支付萝卜升级矿山”按钮。玩家本局累计用于召唤佣兵的萝卜达到门槛后，萝卜田自动升级，同时提高容量和每回合固定金币收入。

| 萝卜田等级 | 累计佣兵消费门槛 | 萝卜容量 | 每回合固定金币收入 |
|---|---:|---:|---:|
| 1级 | 0 | 12 | 0金 |
| 2级 | 9 | 24 | 10金 |
| 3级 | 20 | 40 | 25金 |
| 4级 | 35 | 60 | 45金 |
| 5级 | 55 | 90 | 70金 |
| 6级 | 75 | 150 | 100金 |

这里采用“累计门槛”，不是每次额外再交一笔升级费。例如累计召唤佣兵花到20萝卜，就直接到3级。抽升级石的消费不计入这个进度，否则玩家抽石也能同时得到佣兵路线的经济奖励，两条选择会失去差异。

界面名称建议使用“萝卜经济收入”或“营地收入”，避免和项目现有的5%金币利息混为同一个公式。结算顺序建议固定为：

1. 战斗奖励、击杀奖励和其他原有金币收入。
2. 按原规则计算现有百分比金币利息。
3. 加上萝卜田提供的固定金币收入。
4. 进入下一回合，结算萝卜采集。

固定收入在本回合不会再次参与5%利息，玩家看到的结算明细和实际到账也更容易保持一致。

### 2.4 佣兵价格和存续时间

现有12名佣兵的旧金币价格为50、100、150……600。第一版可以按统一比例换成3、6、9……36萝卜，保持强弱和价格顺序：

| 佣兵 | 萝卜价格 | 佣兵 | 萝卜价格 |
|---|---:|---|---:|
| 泡沫术士 | 3 | 炎阳王者 | 21 |
| 甲壳守卫 | 6 | 星轨猎人 | 24 |
| 审判剑士 | 9 | 狂战先锋 | 27 |
| 黄金重骑 | 12 | 黑钢统帅 | 30 |
| 圣愈修女 | 15 | 时空观测者 | 33 |
| 镜像刺客 | 18 | 冥界执行者 | 36 |

实现时给佣兵数据增加 `carrot_cost`，不要覆盖原 `cost` 字段。原 `cost` 仍被战斗击杀赏金等逻辑读取，直接改写会意外改变战斗经济。所有购买按钮和服务端交易改读 `carrot_cost`。

佣兵继续沿用当前规则：只参加接下来的一场战斗，战后清空佣兵栏；本局累计佣兵萝卜消费、萝卜田等级和固定金币收入不会清空。

### 2.5 升级石抽取

- 每次抽取消耗50萝卜。
- 每名玩家每回合最多抽1次，未使用次数不累积。
- 天、地、人三种结果第一版各为三分之一概率，允许重复，不设置保底。
- 联机时由服务器开奖；结果写入不可重复执行的交易回执，断线重连不能重新抽。
- 抽到后直接进入本队共享仓库，不经过玩家个人背包。
- 单人模式使用同一结构，只是仓库里只有自己可以操作。

容量达到60的4级萝卜田才可能持有50萝卜，因此升级石自然在中期以后开放。按钮可以提前显示，但在容量不足时置灰并提示“萝卜田4级后可储存50萝卜”。

### 2.6 团队共享和四星升级

团队仓库分别记录三种石头数量：

```text
天石 sky
地石 land
人石 ren
```

玩家只能升级自己棋盘或待命区里的三星普通棋子。棋子的 `element` 必须和石头类型相同。一次操作消耗一颗团队石头，把目标从三星升为四星。

第一版建议采用以下限制：

- 佣兵不能使用升级石。
- 四星不能通过普通同名合成获得，普通合成仍在三星停止。
- 四星出售时不返还升级石，并在出售前显示一次明确确认。

> **四星本身的属性倍率、技能数值与出售返还，以 `docs/四星技能与数值设计规格.md` 为准。**

同一颗共享石头可能被两名队员同时点击。服务器必须把“检查库存、扣石、升级目标”作为一个原子交易，只允许一个请求成功；失败的一方收到“石头已被队友使用”，并刷新仓库。

## 3. 备战界面方案

### 3.1 3D 萝卜采集区

萝卜和六只宠物放在棋盘右侧的空地，采用参考图的构图：

```text
                    敌方宠物 A   敌方宠物 B   敌方宠物 C
                              \     |     /
                                大萝卜
                              /     |     \
                    友方宠物 A   友方宠物 B   友方宠物 C
```

- 敌对队伍三只宠物位于萝卜上方，朝向下方。
- 友方队伍三只宠物位于萝卜下方，朝向上方。
- 宠物优先使用各座位玩家已经选择的宠物模型；空座位不显示，机器人可用对应机器人配置的宠物。
- 本地玩家宠物可以用脚底光圈或轻微描边区分，不需要额外文字。
- 萝卜田等级只改变萝卜尺寸、叶片数量或地面圈装饰，不改变碰撞区。
- 采集结算时六只宠物播放约1.2秒挖掘动作，萝卜上方浮出“+N萝卜”，随后回到待机。
- 常态挖掘动作可以循环，但资源数字只在进入新回合时改变。
- 这一块3D场景只负责表现，点击入口由固定UI按钮承担，避免模型遮挡棋盘操作。

当前备战布局已经把棋盘靠左并在右侧保留伸缩空间，适合把采集场景挂入备战3D模型层。需要在1600×720、常见手机宽屏和窄屏分别检查萝卜、右侧按钮、棋盘最右列是否互相遮挡。

### 3.2 右侧按钮布局

右下角未来属于聊天系统，因此不要增加第三、第四枚常驻大按钮。保留现在右上动作栏，并把现有两枚竖排按钮改造为：

```text
右上： [战力] [统计] [静音]

右侧： [ 萝卜营地 ]   显示小角标：当前萝卜/容量
       [ 队伍仓库 ]   显示角标：三种石头总数

右下： 预留聊天消息和输入按钮区域，不放萝卜系统按钮
```

“萝卜营地”替换现有“佣兵”按钮，打开居中的模态面板，面板内使用三个页签：

| 页签 | 内容 |
|---|---|
| 采集 | 当前产量、容量、萝卜田等级、下一级佣兵消费门槛、金币升级采集速度 |
| 佣兵 | 复用现有12张佣兵卡；金币图标换成萝卜图标；购买后刷新容量进度和金币收入 |
| 升级石 | 显示50萝卜、本人本回合剩余次数、三种等概率预览和抽取按钮 |

面板顶部始终显示：`萝卜 当前/容量`、`下回合 +产量`、`营地收入 +金币/回合`。玩家切换页签时不会失去对三项核心数字的判断。

“队伍仓库”替换现有“队伍佣兵”按钮，打开后使用两个页签：

| 页签 | 内容 |
|---|---|
| 升级石 | 天/地/人石头数量；列出本人可升级的三星棋子；选择棋子后确认升级 |
| 本回合佣兵 | 保留现有队伍佣兵3D检阅功能 |

仓库石头发生变化时，按钮角标短暂跳动一次。不要弹出强制窗口打断队友操作。

### 3.3 交互反馈

- 萝卜不足：按钮置灰，点击或长按显示差多少。
- 容量已满：萝卜数字显示“满”，采集页提示下回合会溢出多少。
- 佣兵成交：萝卜飞向佣兵卡，容量进度条同步前进；跨过门槛时播放一次萝卜田升级反馈。
- 抽石成功：先扣萝卜并收到服务器结果，再播放开石动画；动画不能决定随机结果。
- 队友使用石头：仓库数量实时刷新，并显示简短队伍消息，例如“队友B使用天石升级了天使”。以后聊天系统完成后，这类系统消息可以进入聊天记录。
- 四星升级：只高亮属性匹配的三星棋子；不匹配棋子保持可见但不可选，并注明需要的石头。

## 4. 状态和数据设计

不要重复存储可以从规则表推导的数据。个人状态建议只增加：

```gdscript
carrots: int = 0
harvest_tech_level: int = 0
merc_carrots_spent_total: int = 0
stone_draw_used_round: int = 0
```

容量、萝卜田等级、每回合固定金币收入和每回合产量都由上述状态及配置表计算。这样调整门槛时不需要迁移四份重复数据。

队伍状态建议增加：

```gdscript
team_upgrade_stones := {
    "sky": 0,
    "land": 0,
    "ren": 0,
}
```

服务端每个座位的备战经济状态需要同步保存个人萝卜字段；升级石放在队伍级房间状态，不放在座位状态。所有萝卜交易和共享石头交易都增加经济修订号，重连时以服务器状态覆盖客户端状态。

建议把数值集中在一个纯规则文件，例如 `scripts/economy/CarrotEconomy.gd`：

```text
基础产量、科技价格、科技加成
佣兵消费门槛、容量、固定金币收入
升级石价格、每回合次数、抽取权重
根据累计佣兵消费计算萝卜田等级
根据等级计算容量和金币收入
```

配置先直接使用常量数组即可，不需要为第一版额外建立编辑器工具或复杂资源类型。

## 5. 联机权威交易

当前项目已经有备战经济账本和请求回执结构，萝卜系统应沿用同一模式。客户端只发送意图，不发送“扣完后我还有多少萝卜”或“我抽到了什么”。至少增加四种动作：

```text
upgrade_harvest_tech  使用金币升级采集科技
hire_merc_carrot      使用萝卜召唤佣兵并累计消费
draw_upgrade_stone    使用萝卜抽石，服务端决定结果并加入队伍仓库
use_upgrade_stone     原子扣除团队石头并把指定棋子升到四星


> 实现说明（2026-09-09）：`use_upgrade_stone` 已落地，见 `EconomyLedger._use_upgrade_stone`
> 与 `NetworkService._room_validate_provenance`。血统按棋子 uid 记在 `prep.four_star_uids`，
> 由 `tools/carrot_online_check.tscn` 与 `tools/piece_uid_check.tscn` 守。
> 账本开关（economy_ledger_enabled）上线后应收敛成 `roster[uid].star == 4` 并删掉 four_star_uids。
```

每个动作必须校验房间、回合、座位、经济修订号和唯一请求ID。重复请求只重放第一次回执，不能重复扣款、重复加石或重新开奖。

四星棋子提交战斗前，服务端还要校验该单位确实由一次成功的升级石交易产生。仅仅允许客户端在棋盘快照里上报 `star = 4` 会留下直接修改客户端制造四星的漏洞。

## 7. 推荐实施顺序

### 阶段A：纯规则和本地状态

1. 增加 `CarrotEconomy.gd` 及数值表。
2. 在 `GameState`、普通存档和教学存档加入字段及旧档默认值。
3. 实现新回合采集、容量截断和固定金币收入。
4. 给佣兵增加萝卜价格并改造本地购买路径。

完成标准：不做新界面也能通过调试入口走完“采集—买佣兵—升级容量—获得金币收入”的循环。

### 阶段B：四星和升级石

1. 区分普通合成上限三星与最终单位上限四星。
2. 清理所有写死 `1..3` 和 `clampi(star, 1, 3)` 的位置。
3. 加入三种升级石、抽取和目标校验。
4. 验证战斗生成、详情面板、伤害结算、出售和存档都能处理四星。

完成标准：三种属性各有一只棋子能合法升四星并完整打完战斗；普通合成不能制造四星。

### 阶段C：服务器权威和共享仓库

1. 扩展座位经济状态和队伍房间状态。
2. 实现四种交易、幂等回执和服务端随机。
3. 重连载入萝卜、科技、消费进度、本回合抽取次数和队伍仓库。
4. 做两人同时抢同一颗石头的并发检查。

## 8. 最小验证清单

- 第一回合只结算一次3萝卜，反复开关面板不会重复领取。
- 科技加成为替换制：2级总产量是9，不是12。
- 容量为12时，11萝卜获得3后变12，不会变14。
- 累计佣兵消费从8到11时只跨到2级，容量变24、固定金币收入变10。
- 抽石不推进佣兵消费门槛。
- 每名玩家同一回合第二次抽石被拒；下一回合恢复一次。
- 三种石头只能升级对应属性三星棋子，佣兵和二星棋子不能升级。
- 普通合成不能从三星变四星。
- 两名队员同时使用最后一颗同类石头时只成功一次。
- 四星进入战斗后属性倍率正确，网络快照不会把它截回三星。
- 佣兵战后清空，但萝卜、科技、累计佣兵消费和队伍石头保留。
- 断线重连后个人萝卜和队伍仓库与服务器一致，抽石不会重新开奖。
- 战斗结算面板显示的固定金币收入与实际到账一致。
- 1600×720、手机宽屏、窄屏下，右侧按钮不遮挡萝卜、棋盘和未来聊天区。
