# AI 五档难度（2026-11-07）

需求：《Glory 游戏 AI 系统升级需求 — 5 档智能难度》。本文写清现状、改了什么、怎么量、怎么部署。

## 一、几条定死的原则

- **只改 AI 怎么做决定。** 不改任何战斗数值，不多给钱、血、攻击，不看隐藏商店和未来随机数。
  AI 的每一笔花钱都走和真人同一份规则（`EconomyLedger` / `EconomyService`）。
- **战斗里不分档。** 这是自走棋：攻击目标、走位、放技能是 `BattleSimulator` 的规则，真人和 AI 共用。
  按难度改它，等于给 AI 的棋子换一套规则——那就是作弊。五档的差距全部来自备战决策。
- **AI 只用真人拿得到的信息。** 不看对手阵容（游戏没有侦察），只记上一场 PvP 赢没赢；
  队友的棋盘真人能看（「查看棋盘」），AI 也能用。
- **AI 关键决策都在战斗服务器上算**，档位由服务器定，客户端改不了。

## 二、改之前的问题（实测 60 种子 × 21 回合）

| 现象 | 原因 |
|---|---|
| 一次升级石都没抽过，四星 0 个 | 抽不起就把萝卜全花在买得起的最贵佣兵上，永远攒不到第一次抽石要的 50 |
| 佣兵栏 8 格，每回合只叫 1 个 | 「买得起的最贵一个」，不凑组合 |
| 第 21 回合平均剩 908 金没花 | 没有决赛全花；第 9 回合起备战席满了只买同名 |
| 采集科技停在 3 级 | `MAX_TECH_LEVEL := 3` 写死 |
| 主种族开局随机、不转型；不认羁绊门槛；站位一条规则；从不看对手 | 规则是写死的 |

## 三、结构

| 文件 | 管什么 |
|---|---|
| `data/ai/bot_profiles.json` | 五档参数（字段含义见 `BotProfile.gd` 文件头）。调参改这里，战斗服务器重启生效 |
| `scripts/economy/ai/BotProfile.gd` | 读档位、段位 → 档位、托管档 |
| `scripts/economy/ai/BotEval.gd` | 静态估值：单位强度 = √(有效血量 × 每秒输出)，羁绊门槛加成，挑上阵 7 人 |
| `scripts/economy/ai/BotCarrots.gd` | 萝卜：抽升级石 / 凑一组佣兵 / 队伍仓库的石头规则 |
| `scripts/economy/ai/BotFormation.gd` | 站位：basic / role，PvP 输了左右翻转 |
| `scripts/economy/BotPlayer.gd` | 线上 AI 座位的大脑（买、卖、刷新、合成、科技、四星、宝藏、站位都按档位） |
| `scripts/economy/LiveBotEconomy.gd` | 每个 AI 座位定哪一档、告诉 AI 队里有没有真人（石头规则要用） |
| `scripts/economy/ai/LegacyBotPlayer.gd` | 🔒 11-07 之前的 AI 原样冻结：教学局、没有线上状态时的后备推演、对战台基准 |

档位从哪来：

| 座位 | 档位 |
|---|---|
| 匹配补位 | 账号服务器按这桌真人的平均排位分算段位（休闲也用排位分），名片签 `ai_tier`；同桌 AI 同一档 |
| 掉线托管 | 普通（`handover_level`，用户定） |
| 自定义房间的 AI | 在座真人段位的平均 |
| 没写的 | `default_level`（普通） |

段位 → 档位：初誓 1 新手 / 森卫 2 简单 / 星铸 3 普通 / 天曜 4 困难 / 荣耀之冠 5 大师。

## 四、五档的差别

| | 新手 | 简单 | 普通 | 困难 | 大师 |
|---|---|---|---|---|---|
| 误判（决策噪声） | 大 | 中 | 小 | 同普通 | 同普通 |
| 冲动消费 | 常有 | 偶尔 | 不 | 不 | 不 |
| 羁绊 | 不懂 | 只认第一档 | 全部门槛 | 同普通 | 同普通 |
| 凑星潜力 | 不看 | 一半 | 看 | 同普通 | 同普通 |
| 主种族 | 开局随机不改 | 按手上最多 | 按估值，可转一次以上 | 同普通 | 同普通 |
| 留钱 | 不留 | 固定 30 | 吃利息，关键回合花 | 同普通 | 同普通 |
| 决赛全花 | 否 | 否 | 是 | 是 | 是 |
| 采集科技 | 不升 | 最多 2 级 | 最多 3 级，升完留 80 | **最多 4 级，升完留 60** | **最多 5 级，升完留 40** |
| 萝卜 | 叫最贵的一个 | 攒着抽升级石 | 攒着抽升级石，Boss / PvP / 决赛回合照样叫佣兵 | 同普通 | 同普通 |
| 四星 | 不升 | 有石有钱就升 | 挑收益最大的 | 同普通 | 同普通 |
| 站位 | 近战前远程后 | 同左 | 坦克 / 输出 / 刺客 / 辅助 | 同普通 | 同普通 |
| PvP 输了 | 不管 | 不管 | 换一种对位 | 同普通 | 同普通 |

困难 / 大师原来还有「噪声更低、更看重凑星、更敢转型、多刷新、关键回合前攒钱、站位看见过的对手、真打几场选站位」。
11-08 在对战台逐项量过，**都没有可测的好处，有几项还更弱**（第七节第五批），已从这两档去掉，只留下采集科技。
其中「站位看见过的对手」（counter + `enemy_info: 2`）和「真打几场选站位」（`BotRollout` / `sim_budget`）
没有档位再用，11-08 用户定删掉代码；`enemy_info` 只剩「输了换对位」一个意思，改名 `flip_on_loss`。
删完同一批种子 40 局逐局结果和删之前一模一样。

队伍仓库的升级石（用户定）：
- 队里有真人时，AI 只用**自己抽的**石头，在仓库里放满 2 回合还在，才拿去升四星。真人队友有没有对应属性的三星都要等。
- 第 21 回合只要真人队友用不上（没有对应属性的三星），AI 可以直接用。
- 真人抽的 AI 一律不碰。全是 AI 的队伍没人可让，仓库里的都能用。
- 仓库只记「天 / 地 / 人各几颗」，AI 在自己状态里记每颗是哪回合抽的；真人把同属性的用掉了，就按「用掉的是 AI 那颗」对账。

## 五、对战台（量 AI 强弱）

```bash
python tools/ai_arena/run_arena.py --a L3 --b legacy --seeds 200 --jobs 12
```

- 六个座位全是 AI，按战斗服务器同一套规则从第 1 回合打到第 21 回合（或一队水晶归零）。
- 每个种子两边各打一次，抵消座位先后的偏差；胜率带 95% 置信区间（Wilson）。
- `legacy` = 11-07 之前的 AI，当固定基准。
- 11-08 之前对战台默认开着大师的真打模拟（线上从没开过），那之前大师的数字含模拟；模拟已删。
- 同一批种子、同一份代码结果完全一样（11-08 验过：L2 对 L3 打 61.3%，换边打 L3 对 L2 正好 38.8%）。
  所以同一批种子打过的组合不用重打，候选之间也可以直接比。
- 一局约 25 秒（MSI 插电单进程）；用电池时 CPU 降频，慢 2–4 倍。1,000 局开 10 个进程约 1 小时；
  10,000 局适合当最终验收跑一个通宵，不适合放进调参循环。
- 结果在 `reports/ai_arena/`（不进仓库）。

门禁：`tools/ai_difficulty_check.tscn`（石头规则、佣兵组合、21 回合不作弊、同种子可复现）。

调参：

```bash
python tools/ai_arena/tune.py --level 5 --rival L4 --candidates 12 --seeds 20 --jobs 10
python tools/ai_arena/tune.py --level 3 --rival L2 --try tries.json --candidates 0 --seeds 40 --seed-base 90000 --no-base
```

在这一档参数附近随机改几项（或 `--try` 点名要试的几组）、和对手档打，同一批种子打所有候选；只认 95% 区间下限超过 50% 的。
`--no-base` 不打原参数（同一批种子打过就不用再打）；`--confirm-seeds 40` 把前几名换一批种子复核。
结果写在 `reports/ai_arena/tune_*/best.json`，确认后再手动并进 `bot_profiles.json`（不自动改线上配置）。
对战台用 `--override=文件` 只在本进程里盖掉档位参数。

**挑赢家会挑中运气好的。** 十几个候选、每个 80 局（区间 ±11 个百分点），第一名几乎总是高估：
11-08 普通档的一个候选第一轮 60%，换种子复核只剩 51%。所以单批结果只当线索，定参数前换一批没用过的种子再打一遍。

## 六、还没做完的

- 困难和普通拉得太近（约 55%，统计上没坐实）；困难 / 大师和普通只差采集科技上限。现有的决策设置已经试遍，
  要拉开得给 AI 加新的本事（例如更好的经济规划、买牌时往后看几回合），不是调参能解决的。
  新本事如果要做「真打几场」这类重计算，得先接进战斗服务器的分片调度（备战期分片算、真人回放优先、忙时退回静态评估）。
- 决策耗时（MSI 插电、单进程）：普通档每回合平均 4.8 ms、最坏 13 ms；旧版 2–7 ms。锁盘时同步跑，
  一桌 3 个 AI 最坏约 40 ms，可以接受。
- 看队友棋盘时，底部金币仍是自己的（棋盘、备战席、上阵数、左栏羁绊都已换成队友的）。

### 首批（n=40，每组 20 个种子两边各打一次）

| 对局 | 前者胜率 | 95% 区间 | 备注 |
|---|---|---|---|
| 普通 vs 旧 AI | 81% | 67–90% | 普通每座位抽 2.3 颗石、2.0 个四星；旧 AI 都是 0 |
| 新手 vs 旧 AI | 31% | 19–47% | 新手囤了 7,800 金（只买严格变强的） |
| 简单 vs 新手 | 94% | 82–98% | |
| 普通 vs 简单 | 51% | 36–66% | 简单囤了 41,480 金（见下面「囤钱漏洞」）；普通三星偏少 |
| 困难 vs 普通 | 65% | 50–78% | 困难在关键回合多叫佣兵、科技更高 |
| 大师 vs 困难 | 51% | 36–66% | 大师的模拟每场 0.33 秒，看不出收益 |

|---|---|---|

### 第四批：两个假设都被否了

| 试了什么 | 结果 | 结论 |
|---|---|---|
| 四星只花买完牌后多出来的钱（不为四星留钱） | 四星 0.8 → 0.1 个；对旧 AI 80% → 63%；对简单 28% | 四星值这个钱，**已撤回** |
| 普通档也冲动消费（impulse 0.3，用 `--override` 只在测试里开） | 对简单 44%，三星 3.7 vs 简单 7.2 | 买得多不是全部原因 |

最可疑的剩下一条：简单档把萝卜全花在佣兵上（约 300），普通档攒萝卜抽石头（约 100）→ 农田等级低、
每回合营地金币少 40 左右，再加上四星本身很贵。「佣兵 + 营地收入」和「石头 + 四星」哪个更划算，
交给对战台调参去试，不再靠猜。

凑星潜力的形状试过线性：一张新卡的潜力会大于给已有的凑对，等于鼓励摊大饼（10.30 回归当场红），定为进度²。

**结论（到这里为止）：** 新的普通档明显强过 11-07 之前的 AI（两批都约 80%）；简单明显强过新手；
但**简单目前比普通还强**，普通 / 困难 / 大师之间也没拉开 —— 五档的顺序还没成立，不能上线。
下一步用对战台调参（`tools/ai_arena/tune.py`）先让普通稳定强过简单，再依次往上。

### 第五批：11-08 通宵调参（每组 40 个种子 × 两边 = 80 局，区间约 ±11 个百分点）

**简单为什么比普通强 —— 拆开简单档逐项换成普通的值，看哪项一换就掉（简单 vs 当时的普通）：**

| 简单档改了什么 | 简单胜率 | 简单的三星 / 四星 / 萝卜花在佣兵上 |
|---|---|---|
| 不改 | 61% | 7.3 / 0 / 300 |
| 萝卜改成攒着抽石头 | **51%** | 4.8 / 1.9 / 90 |
| 不冲动消费 | 72% | 6.7 / 0 / 303（但囤了 8,400 金） |
| 刷新改成普通的 8 次 / 留 40 | 69% | 7.3 / 0 / 300 |
| 噪声、转型、留钱、凑星权重、羁绊认知 | 59–64% | 基本不变 |

简单档的强全在「萝卜全叫佣兵」：佣兵当回合就上场，萝卜花出去还抬农田等级、加营地收入。
不冲动消费反而更强（冲动消费本来就是削弱）。

**普通档试过的改法（普通 vs 简单）：** 只有「攒石头期间 Boss / PvP / 决赛回合照样叫佣兵」（`plan_rounds`）
在两批种子上都比原来好（+12 个百分点左右）。科技上限 4 / 5、刷新 12 次、全叫佣兵、不抽石头、留钱方式都没有单独的好处，
有几项明显更差（科技 2 级 38%、刷新只在差 80 金以上才刷 38%）。

**`bot_profiles.json` 改了两项：** 简单 `carrots: pack → plan`；普通 `carrots: plan → plan_rounds`。
（`BotProfile.gd` 读不到配置时的兜底参数也同步成普通档。）改完对战（种子 90000 起）：

| 对局 | 前者胜率 | 95% 区间 | 前者三星 / 四星 |
|---|---|---|---|
| 普通 vs 简单 | **64%** | 53–74% | 2.5 / 0.8 对 4.7 / 1.8 |
| 简单 vs 新手 | **75%** | 65–83% | 4.4 / 1.8 对 0.6 / 0（新手囤 5,200 金） |
| 普通 vs 旧 AI | **83%** | 73–90% | 1.9 / 0.6 对 5.7 / 0 |
| 困难 vs 普通 | 44% | 34–55% | 困难的几项「高级」设置拖后腿 |
| 大师 vs 困难 | 43% | 32–53% | 含模拟（当时对战台默认开） |

注意普通的三星比简单少一半还赢：差距在用钱的时机（关键回合叫佣兵、科技、四星挑收益），不在凑了多少三星。

新手 < 简单 < 普通的顺序成立。困难 / 大师见下。

**困难档逐项加回去（在新普通档上只加一项，和普通打，50% = 没用）：**

| 加的那一项 | 胜率 |
|---|---|
| 科技上限 4、差 60 金就升 | **59%**（48–69%）；换种子（120000 起）复核 **56%**（45–66%），两批合计 160 局约 57% |
| 留钱按关键回合（`reserve: plan`） | 53% |
| 转型门槛 1.25 | 50% |
| 站位看对手（`counter`）/ 记对手阵容（`enemy_info: 2`） | 正好 50%：两项要一起开才有作用，单开等于没改 |
| 凑星权重 2.5 | 43% |
| 刷新 10 次、差 30 金就刷 | 46% |
| 噪声 0.04 / 0 | 46% / 44% |
| 站位看对手 + 记对手阵容（两项一起开） | 52% |
| 科技 4 / 60 再加上面这两项 | 54%（比只加科技还低） |
| 科技上限 5、差 40 金就升 | 62%（51–72%） |
| 科技上限 4、差 40 金就升 | 60%（49–70%） |

**困难档定为「普通 + 科技上限 4、差 60 金就升」**（两批种子都验过的那组），其余全和普通一样。

**大师档在新困难档上继续加科技（和困难打）：** 上限 5 / 差 40 → 54%；上限 6 / 差 20 → 53%；
上限 5 / 差 0 → 50%；上限 4 / 差 40 → 51%。科技过了 4 级收益递减。
再叠别的：科技 5 / 40 + 只买够好的牌（`buy_threshold 0.3`）54%；+ 关键回合前攒钱 51%；两样都加 51%；
**+ 开模拟（`--rollout 1`，`sim_budget 10`）52.5%**，每局慢几倍。

**大师档定为「困难 + 科技上限 5、差 40 金就升」**，其余和普通一样。

**最终验收（种子 130000 起，调参时从没用过，每组 80 局；合计里加上之前同配置的几批）：**

|---|---|---|---|---|
| 简单 vs 新手 | 80% | 75% | 160 局 78% | 70–83% |
| 普通 vs 简单 | 66% | 64% | 160 局 65% | 58–72% |

**结论：** 新手 < 简单 < 普通很稳；普通 → 大师约 61%，统计上成立。困难夹在中间，四组相邻对局的点估计都是前者赢，
但困难对普通只多约 5 个百分点，区间下限还没过 50% —— 同一组对局三批种子打出 51% / 56% / 59%，80 局一组的波动就有这么大。
要把这一步坐实，要么再打几百局，要么给困难找一项真正有用的新本事。困难和大师现在的差别只在采集科技。

### 囤钱漏洞（游戏规则问题，不是 AI 问题）

利息每回合 5% **不封顶**，金钱套（4 件金钱宝藏）开场按手上金币加血攻：每 1000 金 +10%，最多 +100%。
两者叠在一起，后期「什么都不买、攒到 10,000 金」可能比花钱更强，真人也会发现。要不要给利息封顶，由策划决定；
在那之前 AI 不主动走这条路。
