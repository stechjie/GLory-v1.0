# 结算、语音与后台恢复修复（2026-09-30）

## 语音修复与新界面

旧 Windows DLL/Android AAR 与当前源码不匹配，缺少当前桥接要求的 setAudience 接口，导致界面提前拒绝启动语音并显示“语音组件需要更新”。已重新构建两端插件；Windows debug/release DLL 和配套运行库在 addons/glory_voice/bin/windows，Android AAR 在 addons/glory_voice/bin。

Android 构建只复制 Kotlin 源码到独立临时目录，避免遗留同名 Java 文件引起重复类编译错误；原本地 Java 文件保留。Windows 使用 LiveKit C++ SDK 1.11.0 和 godot-cpp 10.0.0-stable 构建，安装了 Visual Studio 2022 C++ Build Tools。构建依赖位于 C:/Users/WINDOWS/GloryBuild/desktop_voice，不需要拷入游戏资源。

assets/ui/voice 中四个 SVG 是本次原创图标，采用青铜轮廓、翠绿内芯、关闭斜杠，与现有奇幻界面搭配。左键为麦克风，中键为扬声器，右键切换所有人/队友；关闭扬声器不关闭麦克风，关闭麦克风仍可收听。首次开麦仍须用户授予系统录音权限。

## 结算与触摸

最终结算按本地队伍排序，两队守护者从实际回放阵容获取；不存在守护者时不拼接括号。新伤害列汇总该席本回合单位及佣兵伤害，并避免两份回放重复累计。只有 PvP 回放提供最终详情入口；PvE 不显示详情，提供返回菜单及符合条件的自定义房间返回按钮。

新的 TouchScrollContainer 在子按钮处理输入前识别纵向触摸，超过 6 像素阈值取消子项按压，支持从图标开始滑动；普通点击保持原行为。应用于最终结算及四星升级石列表。已用输入事件验证拖动滚动且不会触发升级按钮，尚需手机手感验收。

## 后台恢复

前台恢复先探测原连接；3 秒内没有收到真实 pong 则进入原重连流程。大厅意外断开保留座位/凭据 120 秒，超时释放而不转 AI；主动离开仍按主动离开处理。对局内原有 20 秒 AI 接管机制保留，全员离线房间清理窗口改为 120 秒。后台语音暂停策略保留。

需要客户端及 Godot 战斗服务端同步更新。这不能阻止手机系统暂停或杀死应用；超过保留窗口或服务端关闭房间仍无法原座返回。现有协议号 36，本次没有修改 RPC 签名或增加数据库迁移。

## 安装与人工验收

1. 关闭仍在运行的旧游戏，重启编辑器以加载新版 DLL；重新导出 Windows 游戏和 Android APK 并安装。仅覆盖项目源码不会更新已经安装的旧 EXE/APK。
2. 同步更新并重启 Godot 战斗服务端，避免旧端缺少结算字段或大厅保留策略。本次没有部署远端或导出安装包。
3. 电脑与手机进入同房间，首次授予录音权限；分别验证双向讲话、只听、只发、全部关闭，以及所有人/队友范围。确认旧更新弹窗消失。如仍无声，记录语音状态错误和客户端/服务端日志，继续检查实际 LiveKit 连接与令牌链路。
4. 双方各作为蓝队/红队结束 PvP，检查己方第一、守护者、伤害值；PvE 淘汰检查无详情入口。手机从列表图标开始滑动，确认不卡住、不误升级。
5. 大厅和对局分别切后台 10 秒、60 秒、超过 120 秒后回来，验证窗口内恢复及超时提示。后台进程被杀及系统网络限制需实机覆盖。

## 文件与回退

桌面交付目录的 files/ 保存本次变更后的文件，before/ 保存可取得的修改前文件，均保留项目相对目录；manifest.json 记录新增/覆盖及 SHA-256。verification/ 包含构建与验证日志、界面截图。交付为文件副本，未向 GitHub 推送。

回退时先关闭游戏/编辑器，将 before/ 内文件按原相对路径覆盖回项目。manifest 标记 new 的文件无旧副本，可按清单选择清理；不应清理其他本地新增内容。回退插件时同时回退对应源码与 UI，避免重新出现组件接口不匹配。
