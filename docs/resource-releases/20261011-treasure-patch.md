# 2026-10-11 打断锁链资源补丁

适用客户端：Android 0.0.21 (32)、iOS 0.0.21 (52)。
渠道：internal（内部测试）。base_id：glory-20261011-dd83f60。

本次同步 Drive 36 个文件，并应用用户提供的 3 张同名宝物图片。36 个文件已包含在上述商店客户端内，因此最终增量只有中文卡面、英文卡面和图标三张纹理。原图按项目规则保存在 Drive，资源路径、来源和 SHA-256 见同目录 JSON 清单。

## 上传和测试

1. 打开 https://glorytd-api.duckdns.org/admin/ ，在“发布游戏更新”中新建草稿，名称可填“打断锁链美术更新”。
2. 发布渠道选择“内部测试”，仅勾选 iOS、Android，取消 Windows。
3. 草稿中分别上传 android.zip 和 ios.zip；两个平台的基础版本均填 glory-20261011-dd83f60。
4. 确认平台上传成功后发布，再完全退出并重新打开对应的测试客户端。
5. 检查更新下载成功、登录及进入游戏；在图鉴宝物页查看“打断锁链”图标，抽到该宝物时检查中文卡面，切换英文检查英文卡面。
6. 再次冷启动应正常进入游戏；可另测下载中断后重试。

两个补丁各 1,949,430 字节，内容校验值相同。这是本次 UI 纹理的平台导出恰好一致，不能据此假设所有平台补丁都可以通用。仍按平台分别上传。

不要上传用户提供的 assets.zip，也不要上传 current.zip；它们分别是原始美术包和完整导出包。

## 验证范围

后台 ZIP 验证、原始基线/引擎/原生库/启动器兼容检查、Godot 挂载基础包后覆盖补丁并加载三张纹理均通过。导出工具 7 项测试通过。尚未在手机上完成联网下载和游戏验收，且本次没有在运营后台发布补丁。

导出器现在只允许 ZIP 完成后出现的已知 DummyShader 退出提示，仍拒绝其他错误。制作后续补丁应保留原始平台导入缓存，避免模型重新导入产生无关二进制差异；同一 Godot 自包含引擎目录不要同时启动多个导出进程（共享 packtmp 临时路径）。
