    scenes\prep\PrepBoardController.gd
        bug 文档第 1 条「两个同星级人王交换无效」的修复。
        现场：两只**同星**人王**都在备战区**，互换位置无效；**不同星**的能换 ——
        变量是**星级**，不是「在不在场上」。
        根因：`elif can_merge_cells(...): if not _merge_copies_into_cell(...): return`
        —— `can_merge_cells` 判的是「同 id + 同星 + 未满星」，两只同星人王满足它；
        可「满足它」不等于「这一下合得成」：升星要几份看
        `STAR_UPGRADE_COPIES = {1: 2, 2: 3}`，**2 星还得再凑第 3 份**。
        两只人王互换时凑不出第 3 份 → 返回 false → **静默 return**，既不合成也不交换。
        星级边界正好解释「不同星级可以换」：1 星只要 2 份、旧写法真的**合成**；
        2 星缺第 3 份 → **交换无效**；3 星已到合成上限（`MAX_MERGE_STAR = 3`）、
        `can_merge_cells` 为假 → 本来就走交换。
        → 改成 `elif can_merge_cells(...) and _merge_copies_into_cell(...):`，合不成就落到交换分支。
        四个 handler 都改了（一个 handler 只覆盖一种拖动方向）。
